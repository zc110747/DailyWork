一、选择题（本大题有 10 小题，每小题 3 分，共 30 分。每小题只有一个选项是正确的）
1.−2026 的倒数是（　　）有理数 · 倒数
A. 2026
B. −2026
C. 12026
D. −12026

答案：D

解析：乘积为 1 的两个数互为倒数。因为 −2026 × (−12026) = 1，所以 −2026 的倒数是 −12026。

易错：A 是相反数，C 是 2026 的倒数。负数的倒数仍是负数。

2.下列各数中，最小的数是（　　）有理数 · 绝对值与乘方
A. −|−3|
B. −(−2)
C. 0
D. (−1)2

答案：A

解析：先化简再比较：−|−3| = −3，−(−2) = 2，0 = 0，(−1)2 = 1。
因为 −3 < 0 < 1 < 2，所以最小的数是 −3。

易错：−|−3| 是先求绝对值再取相反数，等于 −3，不是 3。

3.若 ∠A = 32°18′，则 ∠A 的余角是（　　）图形 · 余角与补角
A. 57°42′
B. 57°82′
C. 67°42′
D. 147°42′

答案：A

解析：90° − 32°18′ = 89°60′ − 32°18′ = 57°42′。

借位法则：1° = 60′，不够减时把 1° 换成 60′。B 错在分位写成 82′（分不能超过 59），D 求的是补角。

4.下列各组式子中，属于同类项的是（　　）整式 · 同类项
A. 2a2b 与 2ab2
B. −3xy 与 3yx
C. 5a 与 5a2
D. 4m2n 与 −4mn2

答案：B

解析：同类项要求所含字母相同，且相同字母的指数也相同。−3xy 与 3yx 只是字母书写顺序不同，字母与指数完全一致，是同类项。
A、D 中 a、b（或 m、n）的指数正好互换；C 中 a 的指数一个是 1、一个是 2，都不是同类项。

同类项与系数无关，也与字母的书写顺序无关。

5.一个两位数，十位上的数字是 a，个位上的数字是 b。把这个两位数的十位数字与个位数字对调，得到一个新两位数，则新两位数与原两位数的和是（　　）代数式 · 用字母表示数
A. 11(a + b)
B. 10(a + b)
C. 11ab
D. 9(a − b)

答案：A

解析：原两位数是 10a + b，对调后是 10b + a。
两数之和为 (10a + b) + (10b + a) = 11a + 11b = 11(a + b)。

注意两位数的表示方法：十位数字要乘 10，不能直接写成 ab。

6.下列变形正确的是（　　）一元一次方程 · 等式的基本性质
A. 由 a = b，得 ac = bc
B. 由 ac = bc，得 a = b
C. 由 a2 = b2，得 a = b
D. 由 ac = bc，得 a = b

答案：B

解析：等式两边同乘一个数，结果仍是等式，所以 B 正确。
A、D 中若 c = 0，则不能作除数或约去 c，变形不成立；C 中 a2 = b2 时 a 与 b 可能互为相反数，如 a = 2、b = −2，此时 a ≠ b。

等式性质的关键限制：除数（或约去的因式）不能为 0。

7.若 |a| = 3，|b| = 2，且 a < b，则 a + b 的值是（　　）有理数 · 绝对值与分类讨论
A. −5 或 −1
B. −1 或 1
C. −5
D. −1

答案：A

解析：由 |a| = 3 得 a = 3 或 a = −3；由 |b| = 2 得 b = 2 或 b = −2。
由 a < b 判断：
① a = 3 时，b 只能取 2 或 −2，都不满足 3 < b，故 a = 3 不成立；
② a = −3 时，b = 2 满足 −3 < 2，此时 a + b = −1；b = −2 满足 −3 < −2，此时 a + b = −5。
所以 a + b = −5 或 −1。

先由 a < b 剔除不合题意的情况，再求和，不能把四种组合全加起来。

8.如图，直线 AB、CD 相交于点 O，OE ⊥ AB，且 ∠COE = 28°，则 ∠BOD 的度数是（　　）图形 · 相交线与垂线
A. 28°
B. 62°
C. 72°
D. 152°

答案：B

解析：因为 OE ⊥ AB，所以 ∠AOE = 90°。
∠AOC = ∠AOE − ∠COE = 90° − 28° = 62°。
又 ∠BOD 与 ∠AOC 是对顶角，所以 ∠BOD = ∠AOC = 62°。

D 选项 152° 是把 62° 当成了所求的邻补角，注意区分对顶角（相等）与邻补角（互补）。

9.某班分组参加活动：每组 5 人则多 3 人，每组 6 人则少 4 人。设分成的组数为 x，则可列方程（　　）一元一次方程 · 应用（分配问题）
A. 5x + 3 = 6x − 4
B. 5x − 3 = 6x + 4
C. 5x + 3 = 6x + 4
D. 5x − 3 = 6x − 4

答案：A（顺便可得 x = 7，全班 38 人）

解析：抓住“学生人数不变”这个等量关系。
每组 5 人、分 x 组，还剩 3 人没分进组，人数为 5x + 3；
每组 6 人、分 x 组，还差 4 人才够分，人数为 6x − 4。
所以 5x + 3 = 6x − 4。

“多”与“少”直接决定加号还是减号，这一步最容易出错。

10.观察下列等式：
第①个：12 + 2×1 = 3 = 22 − 1；第②个：22 + 2×2 = 8 = 32 − 1；
第③个：32 + 2×3 = 15 = 42 − 1；……
按此规律，第 n 个等式的右边是（　　）代数式 · 规律探究
A. (n + 1)2 − 1
B. n2 − 1
C. (n + 1)2 + 1
D. (n − 1)2 − 1

答案：A

解析：三个等式的右边依次是 22 − 1、32 − 1、42 − 1，底数比序号大 1，故第 n 个等式的右边是 (n + 1)2 − 1。
代数验证：n2 + 2n = (n2 + 2n + 1) − 1 = (n + 1)2 − 1，与等式左边一致。

找规律要看“序号 → 数值”的对应关系：n = 1 时右边是 3，代入 (n+1)2 − 1 得 3，而 n2 − 1 得 0，故排除 B。

二、填空题（本大题有 6 小题，每小题 4 分，共 24 分。第 11、13 题每空 2 分）
11.计算：(−1)2026 − (−2)3 = 。

答案：9

解析：(−1)2026 = 1（偶次幂为正），(−2)3 = −8，
所以原式 = 1 − (−8) = 1 + 8 = 9。

易错：把 (−2)3 算成 8，或把减负数直接加 8 时漏掉了前面的 1。

12.一个数的平方等于 16，这个数是 。

答案：±4

解析：因为 42 = 16，(−4)2 = 16，所以这个数是 4 或 −4，即 ±4。

只写 4 不给分——“平方等于 16 的数”有两个，“16 的算术平方根”才只有一个。

13.单项式 −3x2y5 的系数是 ，次数是 。

答案：−35；3

解析：单项式中的数字因数叫系数，此处系数为 −35（负号要带上）；
次数是所有字母的指数之和：x 的指数是 2，y 的指数是 1，2 + 1 = 3。

分母中的 5 属于系数，不能算进次数。

14.若 a2 + a = 2，则 3 − 2a2 − 2a = 。

答案：−1

解析：3 − 2a2 − 2a = 3 − 2(a2 + a) = 3 − 2×2 = −1。

把 a2 + a 整体看作一个数，不必求出 a 的值（a 本身并不是整数）。

15.8 点 30 分时，钟面上时针与分针所成的角（小于 180° 的角）是 度。
（提示：分针每分钟转 6°，时针每分钟转 0.5°）

答案：75

解析：以 12 点方向为 0°。
分针指向 6，转了 30×6° = 180°；
时针从 8 点起又走了 30 分钟，共转 8×30° + 30×0.5° = 240° + 15° = 255°。
夹角 = 255° − 180° = 75°。

易错：直接用 8×30° = 240° 与 180° 相减得 60°，漏掉了时针在 30 分钟里多走的 15°。

16.观察下列一组数：12，25，310，417，…… 按此规律，第 5 个数是 。

答案：526

解析：分子依次是 1，2，3，4，…，第 n 个数的分子是 n。
分母依次是 2，5，10，17，…，相邻两项的差为 3，5，7，…，即第 n 个数的分母是 n2 + 1。
所以第 5 个数是 552+1 = 526。

验证：n = 1 时分母 1+1 = 2，n = 2 时 4+1 = 5，n = 3 时 9+1 = 10，n = 4 时 16+1 = 17，全部吻合。

17.（本题 6 分）计算：有理数 · 混合运算

（1）−6 ÷ (−3) + (−2)3 × 14；

（2）√49 − |−3| + (−1)2025。

（1）原式 = 2 + (−8) × 14 = 2 + (−2) = 0

（2）原式 = 7 − 3 + (−1) = 7 − 3 − 1 = 3

关键：(−2)3 = −8（负数的奇次幂为负），(−1)2025 = −1（奇次幂为负），√49 = 7。

评分：每小题 3 分。(1) 算对 (−2)3 = −8 得 1 分，顺序与结果正确得 2 分；(2) 算对 (−1)2025 = −1、√49 = 7 各占 1 分，结果 1 分。

自评： / 6 分
18.（本题 6 分）解方程：一元一次方程 · 解法

（1）4x + 3 = 2(x − 1) + 7；

（2）x − 12 − 2x + 13 = 1。

（1）去括号，得 4x + 3 = 2x − 2 + 7；
合并，得 4x + 3 = 2x + 5；
移项，得 4x − 2x = 5 − 3；
合并，得 2x = 2，所以 x = 1。

（2）去分母（两边同乘 6），得 3(x − 1) − 2(2x + 1) = 6；
去括号，得 3x − 3 − 4x − 2 = 6；
合并，得 −x − 5 = 6；
移项，得 −x = 11，所以 x = −11。

评分：(1) 3 分（去括号 1 分，移项合并 1 分，结果 1 分）；(2) 3 分（去分母 1 分，去括号 1 分，结果 1 分）。去分母时漏乘右边的 1 或漏加括号，本题不得分。

自评： / 6 分
19.（本题 6 分）先化简，再求值：2(x2 − 2xy) − 3(x2 − xy) + x2，其中 x = −2，y = 12。整式 · 化简求值

解：原式 = 2x2 − 4xy − 3x2 + 3xy + x2
= (2 − 3 + 1)x2 + (−4 + 3)xy
= −xy。

当 x = −2，y = 12 时，原式 = −(−2)×12 = 1。

评分：去括号正确 2 分，合并同类项得 −xy 2 分，代入求值 2 分。化简结果若写成 0x2 − xy 也算正确。

自评： / 6 分
20.（本题 8 分）如图，点 C、D 在线段 AB 上，且 AC = BD，M、N 分别是 AC、BD 的中点。图形 · 线段的和差 · 代数式

（1）若 AB = 10 cm，CD = 4 cm，求 AC 的长；

（2）若 AB = a，CD = b，用含 a、b 的式子表示 MN 的长（要求写出推理过程）。

（1）因为点 C、D 在线段 AB 上，所以 AB = AC + CD + DB。
又 AC = BD，所以 2AC + CD = AB，即 2AC + 4 = 10，
解得 AC = 3（cm）。

（2）因为 M 是 AC 的中点，所以 MC = ½AC；因为 N 是 BD 的中点，所以 DN = ½BD。
MN = MC + CD + DN = ½AC + CD + ½BD = ½(AC + BD) + CD。
由 AB = AC + CD + BD 得 AC + BD = a − b，
所以 MN = ½(a − b) + b = ½(a + b)。

检验：代入 a = 10，b = 4，得 MN = ½(10 + 4) = 7（cm）。
实际验证：AC = BD = 3，M 距 A 为 1.5，N 距 B 为 1.5，故 MN = 10 − 1.5 − 1.5 = 7（cm），一致。

评分：(1) 3 分（列出 2AC + CD = AB 得 2 分，结果 1 分）；(2) 5 分（表示 MC、DN 各 1 分，拆成 ½(AC+BD) + CD 得 2 分，结果 1 分）。只写结果无过程的给 1 分。

自评： / 8 分
21.（本题 10 分）某文具店 A 种笔记本每本 8 元，B 种笔记本每本 12 元。一元一次方程 · 应用与方案比较

（1）学校购买 A、B 两种笔记本共 20 本，共花了 196 元，求 A、B 两种笔记本各买了多少本；

（2）该店推出促销活动：一次性购买 30 本及以上，全部按总价的 9 折付款。学校计划购买 A 种 15 本、B 种 20 本，应付多少元？

（3）若学校改为只购买 A 种笔记本 29 本，店员说：“您再多买 1 本，总价反而更低。”店员说得对吗？请通过计算说明理由。

（1）设购买 A 种笔记本 x 本，则 B 种为 (20 − x) 本。

依题意得：8x + 12(20 − x) = 196，
去括号，得 8x + 240 − 12x = 196；
合并，得 −4x = −44，解得 x = 11，20 − x = 9。

答：A 种买了 11 本，B 种买了 9 本。（检验：11×8 + 9×12 = 88 + 108 = 196 元 ✓）

（2）总价为 15×8 + 20×12 = 120 + 240 = 360（元）。
因为 15 + 20 = 35 ≥ 30，可享受 9 折，
故应付 360 × 0.9 = 324（元）。

（3）店员说得对，理由如下：
买 29 本时不足 30 本，不享受折扣，应付 29×8 = 232（元）；
若再多买 1 本（共 30 本），可享受 9 折，应付 30×8×0.9 = 216（元）。
因为 216 < 232，且 232 − 216 = 16（元），
所以多买 1 本反而少花 16 元，店员说得对。

评分：(1) 4 分（设元 1 分，列方程 2 分，答 1 分）；(2) 3 分（判断可打折 1 分，算式 1 分，结果 1 分）；(3) 3 分（算出两种情况各 1 分，比较并说明 1 分）。只答“对”而不计算的不得分。

自评： / 10 分
22.（本题 10 分）如图，数轴上点 A、B 表示的数分别是 −6 和 2。点 P 从点 A 出发，以每秒 3 个单位长度的速度沿数轴向右运动；同时点 Q 从点 B 出发，以每秒 1 个单位长度的速度沿数轴向左运动。设运动时间为 t 秒。有理数 · 数轴动点

（1）用含 t 的式子表示点 P、Q 所表示的数；

（2）求点 P 与点 Q 相遇时 t 的值；

（3）当点 P 与点 Q 之间的距离为 4 个单位长度时，求 t 的值。

（1）点 P 从 −6 出发向右每秒走 3 个单位，故点 P 表示的数是 −6 + 3t；
点 Q 从 2 出发向左每秒走 1 个单位，故点 Q 表示的数是 2 − t。

（2）相遇时两点表示的数相同，即 −6 + 3t = 2 − t。
移项合并得 4t = 8，解得 t = 2。
（此时 P、Q 都表示 0，即相遇于原点。）

（3）P、Q 两点间的距离为 |(−6 + 3t) − (2 − t)| = |4t − 8|。
由 |4t − 8| = 4 得 4t − 8 = 4 或 4t − 8 = −4，
解得 t = 3 或 t = 1。

检验：t = 1 时，P 表示 −3，Q 表示 1，距离为 4 ✓；
t = 3 时，P 表示 3，Q 表示 −1，距离为 4 ✓。

评分：(1) 2 分（每写对一个得 1 分）；(2) 3 分（列方程 2 分，结果 1 分）；(3) 5 分（列出绝对值式 2 分，解出一个值得 2 分，两个值齐全得 3 分）。漏解只给部分分。
