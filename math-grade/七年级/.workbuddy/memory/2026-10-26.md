## 踩过的坑（值得记）

1. **SVG 角度弧的 sweep-flag 与数学角反向**：本题坐标系是 `y = cy − r·sinθ`，
   θ 减小（如 178°→132°）在屏幕上是顺时针，必须 `sweep=1`。写错 0 会让弧凸向圆心，
   直接横穿标注文字，看起来像"文字被划掉"。
2. **小跨度圆弧在大半径下退化成直线**（r=62、span=6° 弦长只有 6px），
   会被误读为"杂散短线"；span 提到 16° 才像等角标记。
3. **两栏填空题会因为长题干把空格挤到第二行**，且行高被最高项撑开，视觉发虚；
   改单栏后总高不变（原本就在换行占位），所以**单栏是净收益**。
4. 无头 Edge 截图 + PIL 切片是核验 SVG 图形的有效手段：
   `msedge --headless=new --screenshot --force-device-scale-factor=1.4 --window-size=1120,H`，
   再按行切片放大看细节，比读代码可靠。
5. 答案容错：全角转半角、`或/、/，/和`→逗号后**排序比较**，天然支持"3或7"/"7或3"；
   `°18'` 的直角引号统一成 `′`；`cm/厘米` 剥掉。回归脚本 25 例全过。
6. **排序前必须剥掉正号**：`+4或-4` 拆成 `["+4","-4"]`，`+`(0x2B) 排在 `-`(0x2D) 之前，
   与答案 `4或-4` 的 `["-4","4"]` 不一致 → 误判为错。`keyOf()` 里每个分量先
   `replace(/^\+/,'')` 再 `sort()`，两卷同步修好（0001 25/25、0002 22/22）。

因为 a⁵、8a⁶b³ 这类上标答案学生在输入框里打不出来。

**图形坐标算法（可复用）**：
- 拐点图：先定两平行线与 P 点，夹角 = atan(dy/dx)，平分线斜率取 tan(夹角/2) 再求交点。
  要让平分线交点 Q 落在画布内，就把 P 往左移（P 越靠左 → 夹角越大 → 交点越近）。
- 拼图：大正方形边 a+b，四个 a×b 长方形按风车摆（底 / 右 / 顶 / 左），中心自然空出
  (a−b)²，四块矩形 + 中心恰好铺满、无重叠。
- 直方图：**柱子相邻无间隙**，边界值贴柱缝，纵轴刻度按最大值等分。
