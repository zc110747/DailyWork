一、选择题（本大题有 10 小题，每小题 3 分，共 30 分。每小题只有一个选项是正确的）
1.下列各数中，比 −2 小的数是（　　）有理数 · 大小比较
A. −3
B. −1
C. 0
D. 1

答案：A

解析：两个负数比较大小，绝对值大的反而小。因为 |−3| = 3 > |−2| = 2，所以 −3 < −2。
也可在数轴上比较：越靠左的数越小，−3 在 −2 的左边。

2.−12026 的绝对值是（　　）有理数 · 绝对值
A. −2026
B. −12026
C. 12026
D. 2026

答案：C

解析：一个负数的绝对值是它的相反数，所以 |−12026| = 12026。

注意区分：绝对值一定非负（排除 B），相反数是 12026，倒数是 −2026。

3.2025 年某市常住人口约为 5 420 000 人。将 5 420 000 用科学记数法表示为（　　）有理数 · 科学记数法
A. 54.2×105
B. 5.42×107
C. 0.542×107
D. 5.42×106

答案：D

解析：5 420 000 = 5.42 × 1 000 000 = 5.42×106。
判断方法：原数是 7 位整数，写成 a×10n 时 n = 7 − 1 = 6，且 1 ≤ a < 10。

A、C 中的 54.2 与 0.542 都不满足 1 ≤ a < 10；B 的指数多算了 1 位。

4.下列去括号正确的是（　　）整式 · 去括号
A. a − (b − c) = a − b + c
B. a − (b − c) = a − b − c
C. a + (b − c) = a + b + c
D. a + (b − c) = a − b + c

答案：A

解析：括号前是"−"号，去括号时括号里各项都要变号：a − (b − c) = a − b + c。
括号前是"+"号，去括号时各项都不变号：a + (b − c) = a + b − c。

B 只变了第一项，C、D 把"+"号后面的项变号或漏变号，都是常见错误。

5.若 x = 2 是关于 x 的方程 ax − 3 = 1 的解，则 a 的值是（　　）一元一次方程 · 方程的解
A. 1
B. 2
C. 3
D. 4

答案：B

解析：把 x = 2 代入方程，得 2a − 3 = 1，所以 2a = 4，a = 2。

“方程的解”就是使方程左右两边相等的未知数的值，代入即可，不必先去解含 a 的方程。

6.已知点 C 是线段 AB 的中点，点 D 是线段 BC 的中点。若 AB = 8 cm，则 AD 的长是（　　）图形 · 线段的中点
A. 2 cm
B. 4 cm
C. 6 cm
D. 7 cm

答案：C

解析：C 是 AB 的中点，所以 AC = BC = ½×8 = 4（cm）；
D 是 BC 的中点，所以 CD = ½×4 = 2（cm）；
又 D 在 C 与 B 之间，故 AD = AC + CD = 4 + 2 = 6（cm）。

也可用 AD = AB − BD = 8 − 2 = 6（cm）验证。

7.若 ∠1 与 ∠2 互为余角，且 ∠1 = 3∠2，则 ∠1 的度数是（　　）图形 · 余角
A. 22.5°
B. 45°
C. 60°
D. 67.5°

答案：D

解析：因为 ∠1 与 ∠2 互为余角，所以 ∠1 + ∠2 = 90°。
又 ∠1 = 3∠2，所以 3∠2 + ∠2 = 90°，4∠2 = 90°，∠2 = 22.5°，
故 ∠1 = 3×22.5° = 67.5°。

A 是 ∠2 的度数，问的是 ∠1，别抄错。

8.定义一种新运算：a ※ b = a2 − ab。例如 2 ※ 3 = 22 − 2×3 = −2，则 (−1) ※ (−2) 的值是（　　）有理数 · 新定义运算
A. −3
B. −1
C. 1
D. 3

答案：B

解析：把 a = −1，b = −2 代入规定的式子：
(−1) ※ (−2) = (−1)2 − (−1)×(−2) = 1 − 2 = −1。

易错：后一项是 (−1)×(−2) = 2，减去 2 得 −1；若把 ab 看成 a + b，或漏掉负号，就会得到错误答案。

9.按一定规律排列的一列数：1，3，6，10，15，…，则第 8 个数是（　　）代数式 · 数列规律
A. 36
B. 28
C. 45
D. 55

答案：A

解析：相邻两数的差依次为 2，3，4，5，…，即第 n 个数比第 (n−1) 个数大 n。
依次往下写：15 + 6 = 21（第 6 个），21 + 7 = 28（第 7 个），28 + 8 = 36（第 8 个）。

另解：这列数满足 n(n+1)÷2，第 8 个数 = 8×9÷2 = 36。

B 是第 7 个数，C 是第 9 个数，数序号时容易错位。

10.若 |x − 1| = 2，|y + 1| = 3，且 x < y，则 x + y 的值是（　　）有理数 · 绝对值与分类讨论
A. −5
B. −1
C. 1
D. 1 或 −5

答案：C

解析：由 |x − 1| = 2 得 x = 3 或 x = −1；由 |y + 1| = 3 得 y = 2 或 y = −4。
再用条件 x < y 筛选：
① x = 3 时，无论 y = 2 还是 y = −4，都不满足 3 < y，舍去；
② x = −1 时，y = 2 满足 −1 < 2，此时 x + y = 1；
　　y = −4 不满足 −1 < −4，舍去。
所以 x + y = 1。

D 是本题最大的陷阱：−1 + (−4) = −5 这组不满足 x < y。凡是用两个条件求值，都要逐组检验。

二、填空题（本大题有 6 小题，每小题 4 分，共 24 分）
11.计算：|−7| − (−3) = 。

答案：10

解析：|−7| = 7，减去一个负数等于加上它的相反数，
所以原式 = 7 + 3 = 10。

易错：把 −(−3) 算成 −3，得 7 − 3 = 4。

12.用四舍五入法把 3.14159 精确到 0.001，结果是 。

答案：3.142

解析：精确到 0.001 即保留到千分位，看万分位上的数字 5，按“满 5 进 1”，
3.1415 9 → 3.142。

答案末尾的 2 是有效数字，不能写成 3.14；也不必写成 3.1416（那是精确到 0.0001）。

13.若单项式 2xmy3 与 −5x2yn 的和仍是单项式，则 mn = 。

答案：8

解析：两个单项式的和仍是单项式，说明它们能合并，即它们是同类项。
所以 m = 2，n = 3，故 mn = 23 = 8。

“和仍是单项式”是同类项的另一种说法，不要直接去求 m 与 n 的和。

14.若 a − 2b = 3，则 4b − 2a + 1 = 。

答案：−5

解析：4b − 2a + 1 = −2(a − 2b) + 1 = −2×3 + 1 = −5。

注意提取 −2 时括号内要变号：4b − 2a = −2(a − 2b)，符号弄反会得到 7。

15.已知 ∠AOB = 80°，OC 是 ∠AOB 内部的一条射线，且 ∠AOC = 3∠BOC，则 ∠BOC 的度数是 度。

答案：20

解析：因为 OC 在 ∠AOB 内部，所以 ∠AOC + ∠BOC = ∠AOB = 80°。
又 ∠AOC = 3∠BOC，所以 3∠BOC + ∠BOC = 80°，4∠BOC = 80°，
故 ∠BOC = 20°。

问的是 ∠BOC（小的那个），∠AOC = 60°。

16.如图是某月的月历，用一个方框框出相邻的四个数（2 行 2 列）。若方框内左上角的数记为 x，则这四个数的和是 （用含 x 的式子表示）。

答案：4x + 16

解析：月历中同一行的相邻两数相差 1，同一列的相邻两数相差 7。
左上角的数是 x，则右上角是 x + 1，左下角是 x + 7，右下角是 x + 8。
四数之和 = x + (x + 1) + (x + 7) + (x + 8) = 4x + 16。

验证：图中方框内的四个数是 12、13、19、20，和为 64；
代入 x = 12：4×12 + 16 = 64，一致。

18.（本题 6 分）解方程：一元一次方程 · 解法

（1）3(x − 2) = 5x + 4；

（2）3x − 14 − 5x + 16 = 1。

（1）去括号，得 3x − 6 = 5x + 4；
移项，得 3x − 5x = 4 + 6；
合并，得 −2x = 10，所以 x = −5。

（2）去分母（两边同乘 12），得 3(3x − 1) − 2(5x + 1) = 12；
去括号，得 9x − 3 − 10x − 2 = 12；
合并，得 −x − 5 = 12；
移项，得 −x = 17，所以 x = −17。

评分：(1) 3 分（去括号 1 分，移项合并 1 分，结果 1 分）；(2) 3 分（去分母 1 分，去括号 1 分，结果 1 分）。去分母时漏乘右边的 1，或去括号时括号前是负号却只变第一项，本题不得分。

19.（本题 6 分）先化简，再求值：5ab − [2a2b − (3ab − a2b)]，其中 a = −1，b = 2。整式 · 化简求值（含中括号）

解：原式 = 5ab − [2a2b − 3ab + a2b]
= 5ab − [3a2b − 3ab]
= 5ab − 3a2b + 3ab
= 8ab − 3a2b。

当 a = −1，b = 2 时，
原式 = 8×(−1)×2 − 3×(−1)2×2 = −16 − 6 = −22。

评分：去小括号 2 分，去中括号 2 分，代入求值 2 分。去括号时括号前是"−"号而未变号的，按步扣分。

自评： / 6 分
20.（本题 8 分）如图，∠AOB = 90°，OC 平分 ∠AOB，OD 在 ∠BOC 内部，且 ∠BOD = 2∠COD。图形 · 角平分线与角的和差

（1）求 ∠BOC 的度数；

（2）求 ∠COD 的度数；

（3）求 ∠AOD 的度数。

（1）因为 OC 平分 ∠AOB，所以 ∠BOC = ½∠AOB = ½×90° = 45°。

（2）因为 OD 在 ∠BOC 内部，所以 ∠BOD + ∠COD = ∠BOC = 45°。
又 ∠BOD = 2∠COD，所以 2∠COD + ∠COD = 45°，3∠COD = 45°，
故 ∠COD = 15°。

（3）∠AOC = ½∠AOB = 45°，
所以 ∠AOD = ∠AOC + ∠COD = 45° + 15° = 60°。

另解：∠BOD = 2∠COD = 30°，故 ∠AOD = ∠AOB − ∠BOD = 90° − 30° = 60°。

评分：(1) 2 分；(2) 3 分（写出 ∠BOD + ∠COD = 45° 得 2 分，结果 1 分）；(3) 3 分（求出 ∠AOC 或 ∠BOD 得 2 分，结果 1 分）。

自评： / 8 分
21.（本题 6 分）我们规定一种新运算"△"：a △ b = 2a + b。例如 1 △ 3 = 2×1 + 3 = 5。整式 · 新定义与方程

（1）计算：2 △ (−1)；

（2）若 x △ 3 = 3 △ x，求 x 的值。

（1）2 △ (−1) = 2×2 + (−1) = 4 − 1 = 3。

（2）x △ 3 = 2x + 3，3 △ x = 2×3 + x = 6 + x。
由题意得 2x + 3 = 6 + x，
移项合并得 x = 3。

检验：3 △ 3 = 2×3 + 3 = 9，两边相等 ✓

评分：(1) 2 分；(2) 4 分（正确写出 2x + 3 与 6 + x 各 1 分，列方程 1 分，结果 1 分）。

自评： / 6 分
22.（本题 6 分）甲、乙两地相距 260 千米。一辆汽车从甲地开往乙地，每小时行驶 60 千米。1 小时后，另一辆汽车从乙地出发开往甲地，每小时行驶 40 千米。一元一次方程 · 应用（行程问题）

（1）从第一辆汽车出发算起，经过几小时两车相遇？

（2）相遇处距甲地多少千米？

（1）设从第一辆汽车出发算起，经过 x 小时两车相遇。

此时第一辆汽车行驶了 60x 千米；第二辆汽车晚出发 1 小时，只行驶了 (x − 1) 小时，路程为 40(x − 1) 千米。

两车相向而行，路程之和等于全程，得：60x + 40(x − 1) = 260。

去括号，得 60x + 40x − 40 = 260；
合并，得 100x = 300，解得 x = 3。

答：从第一辆汽车出发算起，经过 3 小时两车相遇。

（2）相遇处距甲地的路程就是第一辆汽车行驶的路程：60×3 = 180（千米）。

检验：第一辆行 180 千米，第二辆行 40×(3−1) = 80 千米，180 + 80 = 260 ✓

评分：(1) 4 分（设元 1 分，把第二辆的时间表示成 x − 1 得 1 分，列方程 1 分，结果 1 分）；(2) 2 分。

自评： / 6 分
23.（本题 8 分）如图，∠AOB = 90°。射线 OC 从 OA 的位置开始，绕点 O 按顺时针方向转动，速度为每秒 3°。设转动时间为 t 秒（0 < t < 60）。图形 · 角的动态问题

（1）当 t = 10 时，求 ∠AOC 与 ∠BOC 的度数；

（2）当 OC 平分 ∠AOB 时，求 t 的值；

（3）当 ∠BOC = 30° 时，求 t 的值。

（1）t = 10 时，OC 转过的角度为 3°×10 = 30°，即 ∠AOC = 30°。
因为 OC 在 ∠AOB 内部，所以 ∠BOC = ∠AOB − ∠AOC = 90° − 30° = 60°。

（2）OC 平分 ∠AOB 时，∠AOC = ½×90° = 45°，
所以 3t = 45，解得 t = 15。

（3）分两种情况：
① OC 还在 ∠AOB 内部（即 0 < t < 30）时，∠BOC = 90° − 3t，
　由 90° − 3t = 30° 得 3t = 60°，t = 20；
② OC 已越过 OB（即 30 < t < 60）时，∠BOC = 3t − 90°，
　由 3t − 90° = 30° 得 3t = 120°，t = 40。
所以 t = 20 或 t = 40。

检验：t = 20 时 ∠AOC = 60°，∠BOC = 30° ✓；t = 40 时 ∠AOC = 120°，∠BOC = 120° − 90° = 30° ✓

评分：(1) 2 分（两个角各 1 分）；(2) 2 分（列式 1 分，结果 1 分）；(3) 4 分（只求出 t = 20 得 2 分，两种情况都求出得 4 分）。
