一、选择题（本大题有 10 小题，每小题 3 分，共 30 分。每小题只有一个选项是正确的）
1.下列计算正确的是（　　）整式的乘除 · 幂的运算
A. a2·a3 = a6
B. (a2)3 = a6
C. a6 ÷ a3 = a2
D. (2a)3 = 6a3

答案：B

解析：A 应为 a5；C 应为 a3；D 应为 8a3（2 也要立方）。B 正确。

2.若分式 x + 1x − 3 有意义，则 x 应满足的条件是（　　）分式 · 有意义的条件
A. x = 3
B. x ≠ 3
C. x = −1
D. x ≠ −1

答案：B

解析：分母 x − 3 ≠ 0，所以 x ≠ 3。

分子 x + 1 是否等于 0 只影响分式的值，不影响分式是否有意义。

3.二元一次方程组 x + y = 4x − y = 2 的解是（　　）二元一次方程组 · 解法
A. x = 3y = 1
B. x = 1y = 3
C. x = −3y = 1
D. x = 3y = −1

答案：A

解析：两式相加得 2x = 6，x = 3；代入 x + y = 4 得 y = 1。

检验：3 + 1 = 4 ✓，3 − 1 = 2 ✓

4.因式分解 x2 − 6x + 9 的结果是（　　）因式分解 · 完全平方公式
A. (x + 3)2
B. (x − 3)(x + 3)
C. (x − 3)2
D. (x − 6)2

答案：C

解析：x2 − 6x + 9 = x2 − 2·x·3 + 32 = (x − 3)2。

一次项是"−6x"，中间取负号，所以是 (x − 3)2 而不是 (x + 3)2。

5.计算 (−2)−2 的结果是（　　）整式的乘除 · 负整数指数幂
A. −4
B. 4
C. 14
D. −14

答案：C

解析：(−2)−2 = 1(−2)2 = 14。

负指数表示取倒数，平方后负号被消去，结果是正数。

6.若 x + y = 5，x − y = 1，则 xy 的值是（　　）整式的乘除 · 完全平方公式
A. 4
B. 5
C. 6
D. 12

答案：C

解析：由 (x + y)2 − (x − y)2 = 4xy，得
4xy = 52 − 12 = 24，所以 xy = 6。

另解：解方程组得 x = 3，y = 2，xy = 6。

7.分式方程 2x − 3 = 3x 的解是（　　）分式方程 · 解法
A. 9
B. 3
C. −9
D. 无解

答案：A

解析：两边同乘 x(x − 3)，得 2x = 3(x − 3)，即 2x = 3x − 9，解得 x = 9。
检验：x = 9 时，x(x − 3) = 54 ≠ 0，所以 x = 9 是原方程的解。

8.某班有 40 名学生，其中有 8 人参加科技社团。在统计表中，“参加科技社团”这一组的频率是（　　）数据 · 频数与频率
A. 0.8
B. 0.2
C. 5
D. 32

答案：B

解析：频率 = 频数 ÷ 总数 = 8 ÷ 40 = 0.2。

频率是不超过 1 的数，A 是“不参加”那一组的频率（32 ÷ 40）。

9.下列说法正确的是（　　）平行线 · 概念辨析
A. 两条直线被第三条直线所截，内错角相等
B. 若 a⊥b，b⊥c，则 a⊥c
C. 同旁内角相等，两直线平行
D. 过一点有且只有一条直线与已知直线垂直

答案：D

解析：A 少了两直线平行的前提；
B 若 a、b、c 在同一平面内，垂直于同一条直线的两条直线互相平行，即 a∥c；
C 判定两直线平行需要用“同旁内角互补”，同旁内角相等推不出平行；
D 是垂线的基本性质，正确。

“垂直”与“平行”的传递性容易混淆：a⊥b、b⊥c → a∥c；a∥b、b∥c → a∥c。

10.若 4x2 + mxy + 9y2 是一个完全平方式，则 m 的值是（　　）整式的乘除 · 完全平方式
A. 12
B. −12
C. ±12
D. 6

答案：C

解析：4x2 + mxy + 9y2 = (2x)2 + mxy + (3y)2，
完全平方式为 (2x ± 3y)2 = 4x2 ± 12xy + 9y2，
比较得 m = ±12。

选 A 或 B 都是漏解；(2x + 3y)2 与 (2x − 3y)2 都满足题意。

二、填空题（本大题有 6 小题，每小题 4 分，共 24 分）
11.计算：(−1)2026 + (π − 3)0 = 。

答案：2

解析：(−1)2026 = 1（偶次幂）；π − 3 ≠ 0，故 (π − 3)0 = 1。
所以原式 = 1 + 1 = 2。

任何非零数的零次幂都等于 1，与底数是不是整数无关。

12.若 a2 − b2 = 6，a − b = 2，则 a + b = 。

答案：3

解析：a2 − b2 = (a + b)(a − b)，
所以 a + b = 6 ÷ 2 = 3。

13.若 |x + y − 3| + (x − y + 1)2 = 0，则 x = 。

答案：1

解析：由非负性得 x + y − 3 = 0 且 x − y + 1 = 0，
即 x + y = 3，x − y = −1。两式相加得 2x = 2，所以 x = 1（此时 y = 2）。

题目问的是 x，不是 y，别把 2 填进去。

14.若分式 x2 − 4x − 2 的值为 0，则 x = 。

答案：−2

解析：需满足分子为 0 且分母不为 0：
x2 − 4 = 0 得 x = 2 或 x = −2；
又 x − 2 ≠ 0，即 x ≠ 2，所以 x = −2。

15.某校 500 名学生中，“每天体育锻炼不少于 1 小时”这一组的频率是 0.15，该组的频数是 人。

答案：75

解析：频数 = 总数 × 频率 = 500 × 0.15 = 75。

16.若 2m = 8，2n = 4，则 2m+n = 。

答案：32

解析：2m+n = 2m·2n = 8 × 4 = 32。

也可先求 m = 3、n = 2，再算 25 = 32；但直接用同底数幂的乘法性质更快。

三、解答题（本大题有 7 小题，共 46 分。解答需写出必要的文字说明、演算步骤或推理过程）
17.（本题 6 分）计算：整式的乘除 · 幂的运算与公式

（1）(−a2)3 + a2·a4；

（2）(2x − 3y)2 − (2x + 3y)(2x − 3y)。

（1）原式 = −a6 + a6 = 0

（2）方法一（先展开）：
原式 = (4x2 − 12xy + 9y2) − (4x2 − 9y2)
= 4x2 − 12xy + 9y2 − 4x2 + 9y2 = −12xy + 18y2

方法二（先提公因式）：
原式 = (2x − 3y)[(2x − 3y) − (2x + 3y)] = (2x − 3y)·(−6y) = −12xy + 18y2

(1) 的两项结果相同、符号相反，加起来是 0——算出 a6 后就收尾的，得 0 分。
(−a2)3 中负号要跟着立方，得 −a6，不是 a6。

评分：每小题 3 分。(1) 两个幂各 1 分，结果 0 得 1 分；(2) 两个公式各 1 分，合并 1 分。

18.（本题 6 分）解方程组：3x + 4y = 102x − 3y = 1二元一次方程组 · 加减消元

解：两个方程中未知数的系数都不相同，先“配系数”再加减。
①×3 得 9x + 12y = 30，　③
②×4 得 8x − 12y = 4。　④
③ + ④ 得 17x = 34，解得 x = 2。

把 x = 2 代入 ①，得 3×2 + 4y = 10，即 4y = 4，y = 1。

所以方程组的解为 x = 2，y = 1。

检验：3×2 + 4×1 = 10 ✓；2×2 − 3×1 = 1 ✓

用代入消元法同样给分，但要先把 2x − 3y = 1 化为 x = 1 + 3y2，代入 3x + 4y = 10 时两边同乘 2 才不会出现分数。

评分：配系数（①×3、②×4）2 分，消元并求出 x 得 2 分，求出 y 得 1 分，写出解并检验 1 分。

自评： / 6 分
19.（本题 6 分）因式分解：因式分解 · 连续使用公式

（1）x3y − 4xy3；

（2）(a2 + b2)2 − 4a2b2。

（1）原式 = xy(x2 − 4y2)
= xy(x + 2y)(x − 2y)

（2）原式 = (a2 + b2)2 − (2ab)2
= (a2 + b2 + 2ab)(a2 + b2 − 2ab)
= (a + b)2(a − b)2

(1) 的公因式是 xy（不是 x），提错会导致 (x2 − 4y2) 变成 (x2 − 4y)，后面全错。
(2) 要把 4a2b2 看成 (2ab)2；两个括号里都要按 a 的降幂重新排列，才看得出是完全平方式。

评分：每小题 3 分。(1) 提公因式 1 分，平方差 2 分；(2) 看出 (2ab)2 得 1 分，平方差 1 分，整理为完全平方式 1 分。

自评： / 6 分
20.（本题 6 分）先化简 (1 − 3x + 2) ÷ x2 − 1x + 2，再求当化简结果为 13 时 x 的值。分式 · 化简与逆向求值

化简：原式 = x + 2 − 3x + 2 ÷ (x + 1)(x − 1)x + 2
= x − 1x + 2 × x + 2(x + 1)(x − 1)
= 1x + 1。

求值：由题意得 1x + 1 = 13，
所以 x + 1 = 3，解得 x = 2。

检验：x = 2 时，x + 2 = 4 ≠ 0，x2 − 1 = 3 ≠ 0，原式有意义。
所以 x = 2。

本题不是“给 x 求值”，而是“给值求 x”，最后一步必须回到原式检验分母是否为零。
若化简出错（例如错写成 x + 1），方程会变成 x + 1 = 13，得到 x = −23，虽能解出但答案错误。

评分：通分 2 分，除法转乘法并因式分解 1 分，化简结果 1 分，列方程求 x 得 1 分，检验 1 分。

自评： / 6 分
21.（本题 8 分）如图，在 △ABC 中，点 D 在边 BC 上，点 E、F 分别在边 AB、AC 上，且 DE∥AC，DF∥AB。平行线 · 性质与比例推理

（1）判断 ∠EDF 与 ∠A 的数量关系，并说明理由；

（2）若 ∠C = 50°，且 ∠EDF : ∠BDE = 3 : 2，求 ∠A 的度数。

（1）∠EDF = ∠A。理由如下：
因为 DE∥AC，
所以 ∠BED = ∠A（两直线平行，同位角相等）。
因为 DF∥AB，
所以 ∠EDF = ∠BED（两直线平行，内错角相等）。
所以 ∠EDF = ∠A。

（2）因为 DE∥AC，
所以 ∠BDE = ∠C（两直线平行，同位角相等）。
因为 ∠C = 50°，所以 ∠BDE = 50°。

又因为 ∠EDF : ∠BDE = 3 : 2，
所以 ∠EDF = 32 × 50° = 75°。

由（1）知 ∠A = ∠EDF，所以 ∠A = 75°。

(2) 不能直接由 ∠C = 50° 推出 ∠A，必须走“∠C → ∠BDE → 按比例求 ∠EDF → 由（1）得 ∠A”这条链。
每一步都要写明用的是哪条平行线的哪个性质（同位角 / 内错角），只写结论不给推理分的扣 2 分。

评分：(1) 4 分（∠BED = ∠A 得 2 分，∠EDF = ∠BED 得 1 分，结论 1 分）；(2) 4 分（∠BDE = ∠C = 50° 得 2 分，按比例求出 ∠EDF = 75° 得 1 分，结论 ∠A = 75° 得 1 分）。

自评： / 8 分
22.（本题 6 分）已知关于 x、y 的方程组 x + y = 52x + ay = 12 的解是正整数，求整数 a 的所有可能值，并写出对应的解。二元一次方程组 · 整数解

解：由 x + y = 5 得 x = 5 − y，代入 2x + ay = 12，得
2(5 − y) + ay = 12，
即 10 − 2y + ay = 12，(a − 2)y = 2。

因为 x、y 都是正整数，所以 y 是正整数，
由 (a − 2)y = 2 知 y 必是 2 的正因数，
所以 y = 1 或 y = 2。

当 y = 1 时，a − 2 = 2，得 a = 4，此时 x = 4；
当 y = 2 时，a − 2 = 1，得 a = 3，此时 x = 3。

答：整数 a 的值为 3 或 4。
当 a = 3 时，方程组的解为 x = 3，y = 2；
当 a = 4 时，方程组的解为 x = 4，y = 1。

必须排除 a = 2 的情形：此时 (a − 2)y = 2 变成 0·y = 2，无论 y 取何值都不成立，方程组无解。
只写“y = 1 或 2”而不说明“y 是 2 的正因数”，推理不完整，扣 1 分。

评分：消去 x 得 (a − 2)y = 2 得 2 分；由正整数条件确定 y = 1 或 2 得 2 分；求出 a 得两个值并写出对应解 2 分。

自评： / 6 分
23.（本题 8 分）为了解学生每周课外阅读的时间，某校随机抽查了 50 名学生，将所得数据整理后绘制成如下频数直方图（每组含前一个边界值，不含后一个边界值），其中 4～6 小时这一组的频数未标出。数据 · 频数直方图 · 中位数 · 样本估计

（1）求 4～6 小时这一组的频数；

（2）求这 50 名学生每周阅读时间的中位数所在的组；

（3）若该校共有 1200 名学生，估计每周阅读时间不少于 6 小时的人数，并判断能否达到“40% 的学生达标”的预期目标。

（1）各组频数之和等于样本容量 50，所以
4～6 小时这一组的频数 = 50 − (4 + 10 + 12 + 4) = 20。

（2）由小到大累加各组频数：
4、14、34、46、50。
50 个数据的中位数是第 25 个与第 26 个数据的平均数，
累计到第 2 组只有 14，到第 3 组才达到 34，
所以第 25、26 个数据都落在 4～6 小时这一组，中位数在 4～6 小时组。

（3）阅读时间不少于 6 小时的是后两组，频数之和为 12 + 4 = 16。
样本中的达标率 = 1650 = 0.32 = 32%。
估计全校约有 1200 × 0.32 = 384（人）。
因为 32% < 40%，所以不能达到预期的 40% 目标。

(2) 中位数只看位置（第 25、26 个），不要与“频数最多的组”（4～6 小时，20 人）混淆——本题恰好两者相同，换成第 (1) 题的 2～4 小时组就会不同。
(3) 的“能否达到”必须用数据比较作答，只写“384 人”不下结论的扣 1 分。

评分：(1) 2 分（补出频数 20）；(2) 3 分（累计频数 2 分，结论 1 分）；(3) 3 分（估计人数 2 分，比较并判断未达标 1 分）。
