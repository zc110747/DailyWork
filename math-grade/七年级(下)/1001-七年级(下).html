一、选择题（本大题有 10 小题，每小题 3 分，共 30 分。每小题只有一个选项是正确的）
1.下列计算正确的是（　　）整式的乘除 · 幂的运算
A. a2·a3 = a6
B. (a2)3 = a5
C. a6 ÷ a2 = a3
D. (ab)2 = a2b2

答案：D

解析：A 应为 a5（同底数幂相乘，指数相加）；B 应为 a6（幂的乘方，指数相乘）；C 应为 a4（同底数幂相除，指数相减）；D 正确（积的乘方，各因式分别乘方）。

三个法则的区别就在指数"加、乘、减"，混用是本章最主要的失分点。

2.若 x = 1，y = −2 是方程 3x − ay = 7 的一个解，则 a 的值是（　　）二元一次方程 · 方程的解
A. −2
B. −1
C. 2
D. 5

答案：C

解析：把 x = 1，y = −2 代入方程，得 3×1 − a×(−2) = 7，
即 3 + 2a = 7，2a = 4，所以 a = 2。

代入时注意 −a×(−2) = +2a，符号弄错会得到 a = −5。

3.若分式 x − 1x + 2 的值为 0，则 x 的值是（　　）分式 · 分式的值为零
A. −2
B. 1
C. 1 或 −2
D. −1

答案：B

解析：分式的值为 0 须同时满足"分子为 0"且"分母不为 0"。
由 x − 1 = 0 得 x = 1；此时 x + 2 = 3 ≠ 0，符合要求，故 x = 1。

C 的陷阱：x = −2 使分母为 0，分式无意义，不能算。

4.因式分解 4x2 − 9 的结果是（　　）因式分解 · 平方差公式
A. (2x − 3)(2x + 3)
B. (2x − 3)2
C. (2x + 3)2
D. (4x − 3)(4x + 3)

答案：A

解析：4x2 − 9 = (2x)2 − 32 = (2x − 3)(2x + 3)。

B、C 是完全平方式的形式，展开后应为 4x2 ± 12x + 9，中间少了一次项，故不能用；D 展开得 16x2 − 9，与原式不符。

5.下列说法正确的是（　　）平行线 · 概念辨析
A. 过一点有且只有一条直线与已知直线平行
B. 两条直线被第三条直线所截，同位角相等
C. 同旁内角互补，两直线平行
D. 若 a∥b，b∥c，则 a 与 c 相交

答案：C

解析：A 少了"过直线外一点"这一前提，若点在直线上就没有与它平行的直线；
B 少了两直线平行的前提，只有两直线平行时同位角才相等；
C 是平行线的判定方法，正确；
D 应为 a∥c（平行于同一条直线的两条直线互相平行）。

6.计算 20 + (−12)−2 的结果是（　　）整式的乘除 · 零指数与负整数指数幂
A. 3
B. 5
C. 54
D. −3

答案：B

解析：20 = 1（任何不等于 0 的数的零次幂都等于 1）；
(−12)−2 = (1−1/2)2 = (−2)2 = 4。
所以原式 = 1 + 4 = 5。

a−n = 1/an（a ≠ 0）。负号在括号里，(−½)−2 的结果是正数 4。

7.如图，AB∥CD，点 E 在直线 AB 与 CD 之间，∠A = 40°，∠C = 30°，则 ∠AEC 的度数是（　　）平行线 · 拐点问题
A. 30°
B. 40°
C. 70°
D. 110°

答案：C

解析：过点 E 作 EF∥AB，则 EF∥CD。
因为 EF∥AB，所以 ∠AEF = ∠A = 40°（两直线平行，内错角相等）；
因为 EF∥CD，所以 ∠CEF = ∠C = 30°；
所以 ∠AEC = ∠AEF + ∠CEF = 40° + 30° = 70°。

拐点问题的通法：过拐点作已知直线的平行线，把大角拆成两个角。

8.某种花粉的直径约为 0.000 003 2 米，将 0.000 003 2 用科学记数法表示为（　　）整式的乘除 · 负指数与科学记数法
A. 3.2×10−5
B. 3.2×10−6
C. 3.2×10−7
D. 32×10−5

答案：B

解析：0.000 003 2 = 3.2 × 10−6。
数小数点后到 3 之前共有 6 个 0（含整数位的 0），故指数为 −6。

绝对值小于 1 的数用科学记数法时，n 为负整数；D 中 32 不满足 1 ≤ a < 10。

9.二元一次方程组 { 2x + y = 7，x − y = 2 } 的解是（　　）二元一次方程组 · 解法
A. { x = 1，y = 3 }
B. { x = 3，y = −1 }
C. { x = −3，y = 1 }
D. { x = 3，y = 1 }

答案：D

解析：两式相加消去 y：(2x + y) + (x − y) = 7 + 2，得 3x = 9，x = 3。
把 x = 3 代入 x − y = 2，得 y = 1。所以解为 x = 3，y = 1。

检验：2×3 + 1 = 7 ✓，3 − 1 = 2 ✓

10.若关于 x 的分式方程 x + mx − 3 = 2 有增根，则 m 的值是（　　）分式方程 · 增根
A. −6
B. 6
C. 3
D. −3

答案：D

解析：方程两边同乘 (x − 3)，得 x + m = 2(x − 3)，即 x = m + 6。
"有增根"说明这个解使最简公分母 x − 3 = 0，即 x = 3。
代入得 3 = m + 6，所以 m = −3。

增根的求法：先解出含参数的解，再令最简公分母为 0，不要直接把 x = 3 代回原方程（那会得到 0 = 2 的矛盾式）。

二、填空题（本大题有 6 小题，每小题 4 分，共 24 分）
11.计算：(−2)3 + (−13)−1 = 。

答案：−11

解析：(−2)3 = −8；(−13)−1 = −3。
所以原式 = −8 + (−3) = −11。

负数的负整数次幂仍为负数，(−⅓)−1 不要写成 3。

12.若 x2 + kx + 9 是一个完全平方式，则 k = 。

答案：±6

解析：x2 + kx + 9 = x2 + kx + 32，而完全平方式为 (x ± 3)2 = x2 ± 6x + 9。
比较一次项系数得 k = ±6。

只填 6 不给分：中间项可正可负，(x − 3)2 同样满足。

13.二元一次方程 2x + 3y = 18 的正整数解共有 组。

答案：2

解析：要求 x、y 都是正整数。由 2x + 3y = 18 得 y 必为偶数，且 3y < 18，故 y 只能取 2 或 4：
y = 2 时 x = 6；y = 4 时 x = 3。（y = 6 时 x = 0，不是正整数，舍去）
所以正整数解为 (6, 2) 与 (3, 4)，共 2 组。

14.在扇形统计图中，某个扇形的圆心角为 72°，则该部分占总体数的百分比是 %。

答案：20

解析：扇形圆心角占整个圆 360° 的比例即为该部分的百分比：
72 ÷ 360 = 0.2 = 20%。

15.已知 a + b = 5，ab = 3，则 a2 + b2 = 。

答案：19

解析：a2 + b2 = (a + b)2 − 2ab = 52 − 2×3 = 25 − 6 = 19。

这是完全平方公式的变形，与 (a − b)2 = (a + b)2 − 4ab 一起，是本册出现频率最高的两个变形。

16.某班共有 40 名学生，其中"每天阅读时间不少于 1 小时"这一组的频率是 0.25，则该组的频数是 人。

答案：10

解析：频率 = 频数 ÷ 总数，故频数 = 总数 × 频率 = 40 × 0.25 = 10（人）。

18.（本题 8 分）解方程（组）：二元一次方程组 · 分式方程

（1）{ 3x + 2y = 8，2x − y = 3 }

（2）2x − 1 = 3x + 1

（1）由 2x − y = 3 得 y = 2x − 3。　①
把 ① 代入 3x + 2y = 8，得 3x + 2(2x − 3) = 8，
即 7x − 6 = 8，7x = 14，x = 2。
把 x = 2 代入 ①，得 y = 1。
所以方程组的解为 x = 2，y = 1。

（2）方程两边同乘 (x − 1)(x + 1)，得 2(x + 1) = 3(x − 1)，
即 2x + 2 = 3x − 3，解得 x = 5。
检验：x = 5 时，x − 1 = 4 ≠ 0，x + 1 = 6 ≠ 0，所以 x = 5 是原方程的解。

评分：(1) 4 分（消元 2 分，求出一个未知数 1 分，结果 1 分）；(2) 4 分（去分母 2 分，求解 1 分，检验 1 分）。分式方程不写检验步骤的扣 1 分。

自评： / 8 分

20.（本题 8 分）先化简，再求值：(1 − 1x + 1) ÷ xx2 − 1，其中 x = 3。分式 · 化简求值

解：原式 = x + 1 − 1x + 1 ÷ x(x + 1)(x − 1)
= xx + 1 × (x + 1)(x − 1)x
= x − 1。

当 x = 3 时，原式 = 3 − 1 = 2。

评分：括号内通分 2 分，除法转乘法并因式分解 3 分，化简结果 1 分，代入求值 2 分。若先代入 x = 3 求数值再算，最多给 3 分。

21.（本题 8 分）如图，在四边形 ABCD 中，AD∥BC，∠A = ∠C。平行线 · 判定与性质

（1）判断 AB 与 CD 的位置关系，并说明理由；

（2）若 ∠A = 110°，求 ∠B 的度数。

（1）AB∥CD。理由如下：
因为 AD∥BC，所以 ∠A + ∠B = 180°（两直线平行，同旁内角互补）。
又因为 ∠A = ∠C，所以 ∠C + ∠B = 180°。
而 ∠B 与 ∠C 是直线 AB、CD 被直线 BC 所截得的同旁内角，
同旁内角互补，所以 AB∥CD。

（2）由（1）知 ∠A + ∠B = 180°，
所以 ∠B = 180° − 110° = 70°。

评分：(1) 5 分（写出 ∠A + ∠B = 180° 得 2 分，转化到 ∠C + ∠B = 180° 得 2 分，判定结论 1 分）；(2) 3 分。结论对但理由只写"因为 AD∥BC"的，扣 2 分。

自评： / 8 分
22.（本题 10 分）学校为开展体育活动，购买足球和篮球共 20 个，足球每个 80 元，篮球每个 100 元，共花费 1760 元。二元一次方程组 · 应用

（1）求购买足球、篮球各多少个；

（2）若商店开展促销：足球按 9 折、篮球按 8 折出售，则购买同样数量的足球和篮球共需多少元？

（1）设购买足球 x 个，篮球 y 个。

依题意得：{ x + y = 20，80x + 100y = 1760 }

由第一个方程得 y = 20 − x，代入第二个方程：
80x + 100(20 − x) = 1760，
即 2000 − 20x = 1760，20x = 240，x = 12。
所以 y = 20 − 12 = 8。

答：购买足球 12 个，篮球 8 个。（检验：12 + 8 = 20，12×80 + 8×100 = 1760 ✓）

（2）12×80×0.9 + 8×100×0.8 = 864 + 640 = 1504（元）。

答：共需 1504 元。

评分：(1) 6 分（设元 1 分，列方程组 3 分，求解 1 分，答 1 分）；(2) 4 分（两个折扣金额各 1.5 分，合计 1 分）。

自评： / 10 分
23.（本题 10 分）为了解学生每天课外阅读的时间，某校随机抽查了 200 名学生，将所得数据整理后绘制成如下频数直方图（每组含前一个边界值，不含后一个边界值）。数据 · 频数与频率 · 频数直方图

（1）求阅读时间在 1.5～2 小时这一组的频率；

（2）若该校共有 1600 名学生，估计每天课外阅读时间不少于 1 小时的人数；

（3）在表示这组数据的扇形统计图中，阅读时间在 0.5～1 小时这一组对应的扇形圆心角是多少度？

（1）由直方图可知，1.5～2 小时这一组的频数是 30。
频率 = 30 ÷ 200 = 0.15。

（2）阅读时间不少于 1 小时的是后两组，频数之和为 70 + 30 = 100（人），占样本的 100 ÷ 200 = 0.5。
所以估计全校约有 1600 × 0.5 = 800（人）。

（3）0.5～1 小时这一组的频数为 60，占总数的 60 ÷ 200 = 0.3。
对应圆心角 = 360° × 0.3 = 108°。

评分：(1) 3 分（读出频数 30 得 2 分，结果 1 分）；(2) 4 分（频数之和 2 分，比例 1 分，结果 1 分）；(3) 3 分（比例 2 分，结果 1 分）。

24.（本题 10 分）如图，用 4 个全等的长方形（长 a、宽 b，且 a > b）拼成一个大正方形，中间空出一个小正方形。整式的乘除 · 乘法公式的几何背景

（1）用两种不同的方法表示中间小正方形的面积，由此写出一个等式；

（2）若 a + b = 10，ab = 21，利用（1）中的等式求 a − b 的值；

（3）若 x + y = 7，xy = 10，求 (x − y)2 与 x2 + y2 的值。

（1）方法一：直接算小正方形，边长为 (a − b)，面积为 (a − b)2；
方法二：大正方形面积减去 4 个长方形的面积，为 (a + b)2 − 4ab。
两者表示同一块面积，所以 (a + b)2 = 4ab + (a − b)2。

（2）由（1）得 (a − b)2 = (a + b)2 − 4ab = 102 − 4×21 = 100 − 84 = 16。
因为 a > b，所以 a − b > 0，故 a − b = 4。

（3）(x − y)2 = (x + y)2 − 4xy = 72 − 4×10 = 49 − 40 = 9；
x2 + y2 = (x + y)2 − 2xy = 49 − 20 = 29。

(2) 中若不加"a > b"的说明，会漏掉 a − b = −4 这个解。

评分：(1) 3 分（两种表示各 1 分，等式 1 分）；(2) 3 分（代入 2 分，取正根并说明 1 分）；(3) 4 分（每问 2 分）。
