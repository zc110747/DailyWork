一、选择题（本大题有 10 小题，每小题 3 分，共 30 分。每小题只有一个选项是正确的）
1.下列计算正确的是（　　）整式的乘除 · 幂的运算
A. a2·a3 = a6
B. (a2)3 = a5
C. a6 ÷ a2 = a3
D. (ab)2 = a2b2

答案：D

解析：A 应为 a5（同底数幂相乘，指数相加）；B 应为 a6（幂的乘方，指数相乘）；C 应为 a4（同底数幂相除，指数相减）；D 正确（积的乘方，各因式分别乘方）。

三个法则的区别就在指数“加、乘、减”，混用是本章最主要的失分点。

2.若 x = 1，y = −2 是方程 3x − ay = 7 的一个解，则 a 的值是（　　）二元一次方程 · 方程的解
A. −2
B. −1
C. 2
D. 5

答案：C

解析：把 x = 1，y = −2 代入方程，得 3×1 − a×(−2) = 7，
即 3 + 2a = 7，2a = 4，所以 a = 2。

代入时注意 −a×(−2) = +2a，符号弄错会得到 a = −5。

3.若分式 x − 1x + 2 的值为 0，则 x 的值是（　　）分式 · 分式的值为零
A. −2
B. 1
C. 1 或 −2
D. −1

答案：B

解析：分式的值为 0 须同时满足“分子为 0”且“分母不为 0”。
由 x − 1 = 0 得 x = 1；此时 x + 2 = 3 ≠ 0，符合要求，故 x = 1。

C 的陷阱：x = −2 使分母为 0，分式无意义，不能算。

4.因式分解 4x2 − 9 的结果是（　　）因式分解 · 平方差公式
A. (2x − 3)(2x + 3)
B. (2x − 3)2
C. (2x + 3)2
D. (4x − 3)(4x + 3)

答案：A

解析：4x2 − 9 = (2x)2 − 32 = (2x − 3)(2x + 3)。

B、C 是完全平方式的形式，展开后应为 4x2 ± 12x + 9，中间少了一次项，故不能用；D 展开得 16x2 − 9，与原式不符。

5.下列说法正确的是（　　）平行线 · 概念辨析
A. 过一点有且只有一条直线与已知直线平行
B. 两条直线被第三条直线所截，同位角相等
C. 同旁内角互补，两直线平行
D. 若 a∥b，b∥c，则 a 与 c 相交

答案：C

解析：A 少了"过直线外一点"这一前提，若点在直线上就没有与它平行的直线；
B 少了两直线平行的前提，只有两直线平行时同位角才相等；
C 是平行线的判定方法，正确；
D 应为 a∥c（平行于同一条直线的两条直线互相平行）。

6.计算 20 + (−12)−2 的结果是（　　）整式的乘除 · 零指数与负整数指数幂
A. 3
B. 5
C. 54
D. −3

答案：B

解析：20 = 1（任何不等于 0 的数的零次幂都等于 1）；
(−12)−2 = (1−1/2)2 = (−2)2 = 4。
所以原式 = 1 + 4 = 5。

a−n = 1/an（a ≠ 0）。负号在括号里，(−½)−2 的结果是正数 4。

7.如图，AB∥CD，点 E 在直线 AB 与 CD 之间，∠A = 40°，∠C = 30°，则 ∠AEC 的度数是（　　）平行线 · 拐点问题
A. 30°
B. 40°
C. 70°
D. 110°

答案：C

解析：过点 E 作 EF∥AB，则 EF∥CD。
因为 EF∥AB，所以 ∠AEF = ∠A = 40°（两直线平行，内错角相等）；
因为 EF∥CD，所以 ∠CEF = ∠C = 30°；
所以 ∠AEC = ∠AEF + ∠CEF = 40° + 30° = 70°。

拐点问题的通法：过拐点作已知直线的平行线，把大角拆成两个角。

8.某种花粉的直径约为 0.000 003 2 米，将 0.000 003 2 用科学记数法表示为（　　）整式的乘除 · 负指数与科学记数法
A. 3.2×10−5
B. 3.2×10−6
C. 3.2×10−7
D. 32×10−5

答案：B

解析：0.000 003 2 = 3.2 × 10−6。
数小数点后到 3 之前共有 6 个 0（含整数位的 0），故指数为 −6。

绝对值小于 1 的数用科学记数法时，n 为负整数；D 中 32 不满足 1 ≤ a < 10。

9.二元一次方程组 2x + y = 7x − y = 2 的解是（　　）二元一次方程组 · 解法
A. x = 1y = 3
B. x = 3y = −1
C. x = −3y = 1
D. x = 3y = 1

答案：D

解析：两式相加消去 y：(2x + y) + (x − y) = 7 + 2，得 3x = 9，x = 3。
把 x = 3 代入 x − y = 2，得 y = 1。所以解为 x = 3，y = 1。

检验：2×3 + 1 = 7 ✓，3 − 1 = 2 ✓

10.若关于 x 的分式方程 x + mx − 3 = 2 有增根，则 m 的值是（　　）分式方程 · 增根
A. −6
B. 6
C. 3
D. −3

答案：D

解析：方程两边同乘 (x − 3)，得 x + m = 2(x − 3)，即 x = m + 6。
“有增根”说明这个解使最简公分母 x − 3 = 0，即 x = 3。
代入得 3 = m + 6，所以 m = −3。

增根的求法：先解出含参数的解，再令最简公分母为 0，不要直接把 x = 3 代回原方程（那会得到 0 = 2 的矛盾式）。

11.计算：(−2)3 + (−13)−1 = 。

答案：−11

解析：(−2)3 = −8；(−13)−1 = −3。
所以原式 = −8 + (−3) = −11。

负数的负整数次幂仍为负数，(−⅓)−1 不要写成 3。

12.若 x2 + kx + 9 是一个完全平方式，则 k = 。

答案：±6

解析：x2 + kx + 9 = x2 + kx + 32，而完全平方式为 (x ± 3)2 = x2 ± 6x + 9。
比较一次项系数得 k = ±6。

只填 6 不给分：中间项可正可负，(x − 3)2 同样满足。

13.二元一次方程 2x + 3y = 18 的正整数解共有 组。

答案：2

解析：要求 x、y 都是正整数。由 2x + 3y = 18 得 y 必为偶数，且 3y < 18，故 y 只能取 2 或 4：
y = 2 时 x = 6；y = 4 时 x = 3。（y = 6 时 x = 0，不是正整数，舍去）
所以正整数解为 (6, 2) 与 (3, 4)，共 2 组。

14.在扇形统计图中，某个扇形的圆心角为 72°，则该部分占总体数的百分比是 %。

答案：20

解析：扇形圆心角占整个圆 360° 的比例即为该部分的百分比：
72 ÷ 360 = 0.2 = 20%。

15.已知 a + b = 5，ab = 3，则 a2 + b2 = 。

答案：19

解析：a2 + b2 = (a + b)2 − 2ab = 52 − 2×3 = 25 − 6 = 19。

这是完全平方公式的变形，与 (a − b)2 = (a + b)2 − 4ab 一起，是本册出现频率最高的两个变形。

16.某班共有 40 名学生，其中“每天阅读时间不少于 1 小时”这一组的频率是 0.25，则该组的频数是 人。

答案：10

解析：频率 = 频数 ÷ 总数，故频数 = 总数 × 频率 = 40 × 0.25 = 10（人）。

21.（本题 8 分）如图，直线 AB、CD 被直线 EF 所截，EG 平分 ∠AEF，FG 平分 ∠CFE，且 EG ⊥ FG 于点 G。判断 AB 与 CD 的位置关系，并说明理由。平行线 · 判定 · 角平分线与垂直

结论：AB∥CD。理由如下：

因为 EG ⊥ FG，
所以 ∠EGF = 90°，
所以 ∠GEF + ∠GFE = 180° − 90° = 90°（三角形内角和）。

因为 EG 平分 ∠AEF，所以 ∠AEF = 2∠GEF；
因为 FG 平分 ∠CFE，所以 ∠CFE = 2∠GFE。
所以 ∠AEF + ∠CFE = 2(∠GEF + ∠GFE) = 2 × 90° = 180°。

∠AEF 与 ∠CFE 是直线 AB、CD 被直线 EF 所截得的同旁内角，
同旁内角互补，所以 AB∥CD。

本题的关键是“先把 90° 平分给两个角，再各自翻倍”，即 ½ 与 2 互为逆运算。
若把 ∠AEF 与 ∠CFE 误判为内错角（相等），结论会变成“两线不平行”，属于性质混淆。

评分：由垂直得 ∠GEF + ∠GFE = 90° 得 3 分；用角平分线写出 ∠AEF = 2∠GEF、∠CFE = 2∠GFE 得 2 分；得出 ∠AEF + ∠CFE = 180° 得 2 分；判定 AB∥CD 并点明“同旁内角互补” 得 1 分。

22.（本题 10 分）某校组织 330 名师生开展研学活动，需租用 A、B 两种客车。A 型车每辆可坐 45 人，租金 800 元；B 型车每辆可坐 30 人，租金 500 元。二元一次方程组 · 方案设计

（1）若共租用 9 辆车且恰好坐满，求 A、B 型车各租多少辆；

（2）若恰好坐满，且 A 型车不少于 3 辆，求所有可能的租车方案；

（3）在（2）的所有方案中，哪种方案租金最低？最低租金是多少元？

（1）设租 A 型车 x 辆，B 型车 y 辆。
依题意得：x + y = 945x + 30y = 330
把 y = 9 − x 代入，得 45x + 30(9 − x) = 330，
即 15x + 270 = 330，15x = 60，x = 4，所以 y = 5。
答：租 A 型车 4 辆，B 型车 5 辆。

（2）由 45x + 30y = 330，两边除以 15 得 3x + 2y = 22。
因为 2y 与 22 都是偶数，所以 3x 也是偶数，x 必为偶数。
又 y = 22 − 3x2 ≥ 0，得 x ≤ 713，
所以 x 只能取 0、2、4、6。结合 x ≥ 3，得 x = 4 或 x = 6。
当 x = 4 时 y = 5；当 x = 6 时 y = 2。
答：共有两种方案——方案一：A 型 4 辆、B 型 5 辆；方案二：A 型 6 辆、B 型 2 辆。

（3）方案一：4 × 800 + 5 × 500 = 3200 + 2500 = 5700（元）；
方案二：6 × 800 + 2 × 500 = 4800 + 1000 = 5800（元）。
因为 5700 < 5800，所以方案一的租金最低，最低租金为 5700 元。

(2) 的完整答案必须交代两件事：为什么 x 是偶数（奇偶性），为什么 x ≤ 713（y ≥ 0）。
只靠试数写出方案而不说明范围的，扣 2 分。

评分：(1) 3 分（列方程组 2 分，结果 1 分）；(2) 4 分（化简为 3x + 2y = 22 得 1 分，奇偶性与范围分析 2 分，两个方案 1 分）；(3) 3 分（两个租金各 1 分，比较与结论 1 分）。

24.（本题 10 分）如图，用 4 个全等的长方形（长 a、宽 b，且 a > b）拼成一个大正方形，中间空出一个小正方形。整式的乘除 · 乘法公式的几何背景

（1）用两种不同的方法表示中间小正方形的面积，由此写出一个等式；

（2）若 a + b = 13，ab = 40，利用（1）中的等式求 a − b 的值，并求出 a、b；

（3）若中间小正方形的面积为 4，四周 4 个长方形的面积之和为 96，求 a + b 的值，并求出 a、b。

（1）方法一：小正方形的边长是 a − b，面积为 (a − b)2；
方法二：大正方形面积减去 4 个长方形的面积，为 (a + b)2 − 4ab。
两者表示同一块面积，所以 (a + b)2 = 4ab + (a − b)2。

（2）由（1）得 (a − b)2 = (a + b)2 − 4ab = 132 − 4×40 = 169 − 160 = 9。
因为 a > b，所以 a − b > 0，故 a − b = 3。
于是 a + b = 13a − b = 3，两式相加得 2a = 16，a = 8，
所以 a = 8，b = 5。（检验：ab = 40 ✓）

（3）小正方形面积为 4，即 (a − b)2 = 4，又 a > b，得 a − b = 2。
4 个长方形的面积之和为 4ab = 96，所以 ab = 24。
由（1）的等式得 (a + b)2 = 4ab + (a − b)2 = 96 + 4 = 100，
因为 a + b > 0，所以 a + b = 10。
于是 a + b = 10a − b = 2，解得 a = 6，b = 4。（检验：ab = 24 ✓）

(3) 是“反向用公式”：题目不给 a − b 也不给 a + b，要先用面积条件分别求出这两个量，才能解出 a、b。
