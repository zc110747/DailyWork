# 方程组处理

问题：已知a，b是实数，关于x，y的方程组

$
\begin{cases}
y = x^3 - ax^2 - bx
\\
y = ax + b
\end{cases}
$

有整数解（x，y），求a，b的取值范围。

**解题思路:**

1. 进行方程组处理，获取y和x的关系
2. 根据(x，y)有整数解，确定x和y的整数解值
3. 将x和y的整数解值代入方程，确定a，b的取值范围

**解:**

将$y = ax + b$带入$y = x^3 - ax^2 - bx$，结果如下。

$
y = x^3 - x(ax+b) \\
= x^3 - xy \\
$

转换后得：

$y + xy = x^3$

则有$y(x + 1) = x^3$。

当$x = -1$时，此时左边为0，右边为-1，不满足要求。

则$x \neq -1$。两边可同时除以$x + 1$。

$
y = \frac{x^3}{x+1} \\
= \frac{(x+1)(x^2 - x + 1)-1}{x+1} \\
= x^2 - x + 1 - \frac{1}{x+1} \\
$

因为（x，y）为整数解，则x+1也为整数。

为了满足y也是整数，则$\frac{1}{x+1}$也要为整数。

那么$x+1 = \pm 1$，x得解为$x = 0或-2$。

带入上式可得：

$
\begin{cases}
x = 0, y = 0
\\
x = -2, y = 8
\end{cases}
$

将$x=0，y=0$带入得$b = 0, a为任意值$。

将$x=-2，y=8$带入得$2a - b + 8 = 0$。

综上所示，满足为a，b整数得条件为（其一即可)：

(1) $b = 0，a为任意实数$ 
(2) $2a - b + 8 = 0$
