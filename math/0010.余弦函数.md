# 余弦函数

设n为正整数，定义$P_n(cosx) = cosnx$, 则

$P_{2025}(cos5^\circ) + 2cos(185^\circ)P_{2024}(cos5^\circ) + P_{2023}(sin85^\circ)得值$

**解题思路：**

1. 公式$sinx = cos(90^\circ - x)$
2. 公式$cos(180^\circ + x) = -cosx$。
3. 公式$cos(m+n) = cos(m)cos(n) - sin(m)sin(n)$
4. 公式$cos(m-n) = cos(m)cos(n) + sin(m)sin(n)$

**解：**

原式转换

$
cos(2025*5^\circ) + 2cos(185^\circ)cos(2024*5^\circ) + P_{2023}(cos5^\circ) \\
= cos(2025*5^\circ) - 2cos(5^\circ)cos(2024*5^\circ) + cos(2023*5^\circ)
$

公式转换:

$
cos(2025*5^\circ) \\
= cos(2024*5^\circ + 5^\circ) \\
= cos(2024*5^\circ)cos(5^\circ) - sin(2024*5^\circ)sin(5^\circ)
$

公式转换:

$
cos(2023*5^\circ) \\
= cos(2024*5^\circ - 5^\circ) \\
= cos(2024*5^\circ)cos(5^\circ) + sin(2024*5^\circ)sin(5^\circ)
$

则

$
cos(2025*5^\circ) + cos(2023*5^\circ)  
= 2cos(2024*5^\circ)cos(5^\circ)
$

原式得值为：

$
2cos(2024*5^\circ)cos(5^\circ) - 2cos(5^\circ)cos(2024*5^\circ) = 0
$
