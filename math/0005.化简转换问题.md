# 化简转换问题

问题：已知实数a、b、x、y满足

$a + b = x + y = 2，ax + by = 5$，求$(a^2 + b^2)xy + ab(x^2 + y^2)$的值。

**解题思路:**

对结果进行因式分解，化繁为简

通过不等式凑出化简后式子

**解:**

将求值进行解析，得值如下。

$
(a^2 + b^2)xy + ab(x^2 + y^2) \\
= a^2xy + b^2xy + abx^2 + aby^2 \\
= (a^2xy + abx^2) + (b^2xy + aby^2) \\
= ax(ay + bx) + by(bx + ay) \\
= (ax + by)(ay + bx)
$

已知：$(a + b)(x + y) = 4$

可得，ax + by + ay + bx = 4，

则有：

$
ay + bx = 4 - (ax + by) \\
= 4 - 5 \\
= -1 \\
$

则最终结果为

$
(a^2 + b^2)xy + ab(x^2 + y^2) \\
= (ax + by)(ay + bx) \\
=  5 * -1 \\
= -5 \\
$
