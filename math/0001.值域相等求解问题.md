# 值域相等求解问题

设$x \in R$，集合$\{x, \sqrt{2x}, x^2\} 和 \{x-4, x^2- 12x + 40, 8x\}$相等, 计算x的值_____。

**解题思路：**

利用值域一致性问题，可以令第一x分别等于右边的三个值，排除不存在项，计算出支持的x

然后将计算出的x代入集合中，验证是否成立。

**解：**

x值等于x - 4, 显然不成立。

x值等于8x，计算出x=0, 左边为$\{0， 0， 0\}$， 右边为$\{-4, 40, 0\}$, 不成立。

x值等于$x^2- 12x + 40$，得公式$x^2- 13x + 40 = 0$, 则x值为5和8(求更公式)，带入集合验证。

x = 5， 带入集合验证为，左边为$\{5， \sqrt{10}， 25\}$， 右边不存在无理数，不成立。

x = 8, 带入集合验证为，左边为$\{8，4，64\}$， 右边为$\{4, 8, 64\}$, 此时成立，则x=8
