# 定义域分段处理问题

问题: 如果x，y是非零实数，使得

$
\begin{cases}
|x| + y = 3
\\
|x|y + x^3 = 0
\end{cases}
$

那么$x + y$的值是多少？

**解题思路:**

分别定义x > 0和x < 0两种情况，验证可行性。

可行计算出x，带入求解$x+y$

**解:**

将$y = 3 - |x|$带入式(2)，则有$x^3 - x^2 +3|x| = 0$。

（1）当x > 0 时，化简为$x^2 - x + 3 = 0$，此时$\Delta < 0$，无实数根。

（2）当x < 0 时，化简为$x^2 - x - 3 = 0$，此时解方程，得根，则$x = \frac{1 \pm \sqrt{13}}{2}$，又因为$x < 0$，则解为$\frac{1 - \sqrt{13}}{2}$。

此时

$
y = 3 - |x| \\
= 3 + x \\
$

可得：

$
x + y \\
= x + 3 + x \\
= 2*x + 3 \\
= 4 - \sqrt{13}
$
