# 0002.函数根转换和韦达定理

已知a，b是函数$(x+1)^2 = 3 - 3(x+1)$的根，则$b\sqrt{\frac{b}{a}}$ + $a\sqrt{\frac{a}{b}}$的值是___。

**变种问题：**

已知不同的值a，b分别满足

$(a+1)^2 = 3 - 3(a+1)$和$(b+1)^2 = 3 - 3(b+1)$

求$b\sqrt{\frac{b}{a}}$ + $a\sqrt{\frac{a}{b}}$的值。

**解题思路**:

方程化简，韦达定理，获取a+b，ab的解

对于输出结果化简，构建ab，a+b相关得表达式，进行计算

**解:**

首先将函数展开，得值如下：

$x^2 + 2x + 1 = 3 - 3x -3$

$x^2 + 5x + 1 = 0$，其中a，b为方程的根值。

因为: $\Delta = 5^2 -1 = 24 > 0$

可根据韦达定理，得出。

$
\begin{cases}
a+b = -5
\\
ab = 1，且a < 0，b < 0
\end{cases}
$

下一步进行结果得计算。

$
b\sqrt{\frac{b}{a}} + a\sqrt{\frac{a}{b}} = \frac{b\sqrt{b^2}}{{\sqrt{ab}}} + \frac{a\sqrt{a^2}}{{\sqrt{ab}}}
$

将 $ab = 1，a < 0，b < 0$ 带入可得。

$
b \cdot -b + a \cdot -a \\
= - (a^2 + b^2) \\
= - ((a + b)^2 - 2ab) \\ 
= -23
$

则最终解为$-23$。
