题目: 已知$x，y，z \in R，且x + y + z = 1，x^2 + y^2 + z^2 = 3$，则xyz的最大值是多少。

**解题思路:**

1. 化简得到xyz基于z的表达式，并求出z的取值范围。
2. 对表达式求导，得出表达式的单调性，确定最大值点。

**解:**

已知

$x + y + z = 1 (1)，\\
x^2 + y^2 + z^2 = 3 (2)$，

通过(1)式平方减去(2)式，化简可以得到如下公式：

$
(x + y + z)^2 - (x^2 + y^2 + z^2) = -2 \\
2(xy  + yz + xz) = -2 \\
xy + xz + yz = -1 \\
xy + (x+y)z = -1 \\
xy = -1 - (x + y)z = -1 - (1-z)z = z^2 - z - 1\\
xyz = z^3 -z^2 - z \\
$

另外$x^2 + y^2 \geq 2xy$，带入上述公式（2）可得：

$3 - z^2 \geq 2xy \\
3 - z^2 \geq 2(z^2 - z - 1) \\
3z^2 - 2z - 5 \leq 0$。

解得$-1 < z < \frac{5}{3}$。


定义$f(z) = z^3 -z^2 - z$，求导得$f'(z) = 3z^2 - 2z - 1 = (3z + 1)(z - 1)$,

$f'(z) >= 0时，z \leq -\frac{1}{3}或z \geq 1，此时单调递增。$

$f'(z) < 0时，-\frac{1}{3} < z < 1，此时单调递减$。结合z的取值范围，可得

在z得取值范围内。

$\{-1，-\frac{1}{3}\}为递增区间，

\{-\frac{1}{3}， 1\}为递减区间，

\{1，\frac{5}{3}\}递增区间$。

则最大值点可以是$-\frac{1}{3}$或$\frac{5}{3}$，分别带入xyz转换关于z的公式可得。

$f(-\frac{1}{3}) = -\frac{1}{27} - \frac{1}{9} + \frac{1}{3} = \frac{5}{27}$。

$f(-\frac{5}{3}) = \frac{125}{27} - \frac{25}{9} - \frac{5}{3} = \frac{5}{27}$。

综上可知，xyz的最大值为$\frac{5}{27}$。
