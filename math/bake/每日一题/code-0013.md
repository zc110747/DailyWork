解题: 已知不全等的a，b，c, 满足如下等式。

$
\begin{cases}
a = ab + c \\
b = bc + a \\
c = ca + b \\
\end{cases}
$

求$a + b + c$的值。

**解题思路:**

1. 三式单独没有意义，相加可以约掉同项，得出某些式子，进一步分析处理。
2. 先构造相加化简，在构建平方和相加化简，然后带入计算处理。

**解:**

三式相加可得

$a + b + c = ab + bc + ca + (a + b + c)$。

则：$ab + bc + ca = 0$。

对上式平方可得

$a^2b^2 + b^2c^2 + c^2a^2 + 2abc(a + b + c) = 0$

即：$a^2b^2 + b^2c^2 + c^2a^2 = -2abc(a + b + c)$

三式平方相加，可得

$a^2 + b^2 + c^2 \\
= a^2b^2 + c^2 + 2abc + b^2c^2 + a^2 + 2abc + c^2a^2 + b^2 + 2abc \\
= (a^2 + b^2 + c^2) + a^2b^2 + b^2c^2 + c^2a^2 + 6abc$

化简可得：$a^2b^2 + b^2c^2 + c^2a^2 + 6abc = 0$

代入上式可得：$-2abc(a + b + c) + 6abc = 0$

转换为，$2abc(3 - (a + b + c)) = 0$

由三式可知，当$a，b, c$任意为0时，带入计算另外两个结果都0。

此时不满足不全等条件，因此a、b、c都不能为0。

那么: $3 - (a + b + c) = 0$。

则可解: $a + b + c = 3$。
