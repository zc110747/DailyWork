解题: 已知$6^x = x^{18}$，求$x$的值。

**解题思路：**

1. 同构思路，先将x和数值放到一边。
2. 然后化简，实现同构处理。

**解：**

将x = 0带入，两边不相等，可得$x != 0$。

将两边同时取$\frac{1}{x}$，化简可得如下:

$(6^x)^{\frac{1}{x}} = (x^{18})^{\frac{1}{x}}$

$6 = (x^{\frac{1}{x}})^{18}$

$6^{\frac{1}{18}} = x^{\frac{1}{x}}$

构造通式转换，可得如下实现

$ (6^2)^{\frac{1}{36}} = x^{\frac{1}{x}}$

$ 36^{\frac{1}{36}} = x^{\frac{1}{x}}$

为了满足左右相等，可得x的值如下所示。

$ x = 36$
