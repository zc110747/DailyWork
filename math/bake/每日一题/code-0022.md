# 计算接近问题

已知$\sqrt15和\sqrt17$，问哪个离4更近？推广到$\sqrt14和\sqrt18$值呢？

结论：值大的距离中间值更近。

转换为证明，对于值$n > 1，\sqrt{n+1}比\sqrt{n-1}更接近\sqrt{n}$

$
\Delta n1 = \sqrt{n+1} - \sqrt{n} \\
= \frac{1}{\sqrt{n+1} + \sqrt{n} }
$

$
\Delta n2 = \sqrt{n} - \sqrt{n-1} \\
= \frac{1}{\sqrt{n} + \sqrt{n-1} }
$

对于n > 1, 可知$\sqrt{n+1} > \sqrt{n-1}$，则

$\sqrt{n+1} + \sqrt{n} > \sqrt{n} + \sqrt{n-1}$

可得$\Delta n1 < \Delta n2$，即$(\sqrt{n+1} - \sqrt{n}) < (\sqrt{n} - \sqrt{n-1})$

将n=16带入，则$\sqrt{17} - 4 < 4 - \sqrt{15}$

这个可以推出一般性，平方后变化固定值，其基础值越大，需要的变化量越小，也就更接近。

例如n=25时，$\sqrt{26}比\sqrt{24}更接近$，$\sqrt{27}比\sqrt{23}$更接近。
