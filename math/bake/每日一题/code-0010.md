# code-0010

求$\sqrt[6]{99 + 70\sqrt{2}}$的值。

**解题思路：**

1. 先考虑完全平方式，将为开三次方。
2. 开三次方，通过立方和公式展开处理。

**解:**

$
99 + 70\sqrt{2} \\
= 49 + 2*7*5\sqrt{2} + 50 \\
= 7^2 + 2*7*(5\sqrt{2}) + (5\sqrt{2})^2 \\
= (7 + 5\sqrt{2})^2
$

则
$
\sqrt[6]{99 + 70\sqrt{2}} \\
= \sqrt[6]{(7 + 5\sqrt{2})^2} \\
= \sqrt[3]{7 + 5\sqrt{2}} $

定义

a = $\sqrt[3]{7 + 5\sqrt{2}}$,

b = $\sqrt[3]{7 - 5\sqrt{2}}$;

则有：

$
ab = -1, \\
a^3 + b^3 = 14
$

立方和公式展开可得：

$
a^3 + b^3 \\
= (a + b)(a^2 - ab + b^2) \\
= (a + b)((a + b)^2 - 3ab) \\
= (a + b)((a + b)^2 + 3) \\
= (a + b)^3 + 3(a + b)
$

可得：$(a + b)^3 + 3(a + b) - 14 = 0$。

令$t = a + b$，带入得：

$t^3 + 3t - 14 = 0$ 

进一步化简得：

$
t^3 - 2t^2 + 2t^2 + 3t - 14 = 0 \\
t^2(t - 2) + (t - 2)(2t + 7) = 0 \\
(t - 2)(t^2 + 2t + 7) = 0
$

且t需要满足实数解，且t^2 + 2t + 7 = 0的$\Delta = 4 - 4*7 < 0$不存在实数解。

所以只有t = 2时，才满足t^3 + 3t - 14 = 0，则可得：$a + b = 2$。

组合得公式：

$
a + b = 2, \\
ab = -1,
$

根据韦达定理，可以a, b为$x^2 - 2x - 1 = 0$的根，且a > 0;

根据求根公式，有$x = 1 \pm \sqrt{2}$。

则$a = 1 + \sqrt{2}$，即为化简后的值。
