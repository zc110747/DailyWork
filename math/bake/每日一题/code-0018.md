### 题目
设$x \in R$，集合$\{x, \sqrt{2x}, x^2\} = \{x-4, x^2-12x + 40, 8x\}$，则x的值是多少。

**选项：**
A. 0
B. 5
C. 8
D. 10

解题思路:

1. 令x分别等于右边的三个数，并计算出x的值。
2. 计算x的值带入集合，判断是否满足要求。

解:

令x = x - 4, 此时不满足要求。

令x = 8x, 此时x = 0, 带入集合不满足要求。

令x = x^2 - 12x + 40, 解得x = 5或8。

x = 5带入集合左边会出现$\sqrt{10}$，不满足要求

x= 8带入集合，左右为{8, 4, 64}, 右边为{4, 8, 64}，集合相等，满足要求。

则结果为x = 8。
