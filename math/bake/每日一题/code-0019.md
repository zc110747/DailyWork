若直角三角形的两条直角边长为a、b，斜边长为c，斜边上的高为h，则有（）

**选项：**

A. $\frac{1}{a} + \frac{1}{b} = \frac{1}{h}$

B. $\frac{1}{a^2} + \frac{1}{b^2} = \frac{1}{h^2}$

C. $a^2 + b^2 = 2h^2$

D. $ab = h^2$

解题思路:

1. 结合直角三角形的勾股定理a^2 + b^2 = c^2
2. 结合直角三角形的面积公式，$s = 1/2 * a * b, s = h * c/2$

解:

$a^2 + b^2 = c^2 (1) \\
ab = hc (2)$

由(2)式可得$c^2 = \frac{a^2b^2}{h^2}$

带入(1)式，得$a^2 + b^2 = \frac{a^2b^2}{h^2}$

两边同时除$a^2b^2$，得$\frac{1}{a^2} + \frac{1}{b^2} = \frac{1}{h^2}$,，结果选择B。
