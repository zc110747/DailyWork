假如x和y是非零实数，使得$|x| + y = 3$和$|x|y + x^3 = 0$，那么$x + y$等于（）

**选项：**

A. $3$

B. $4 + \sqrt{13}$

C. $4 - \sqrt{13}$

D. $3 - \sqrt{13}$

**解：**

假设x为正数, 得公式如下。

$x+y = 3 (1)\\
xy + x^3 = 0 (2)\\
$

将$y=3-x$带入(2)式，并化简得

$x^3 + x(3-x) = 0 \\
x(x^2 - x + 3) = 0 \\
$

此时无非零实数解，不满足要求。

假设x为负数, 得公式如下。

$-x+y = 3 (1)\\
-xy + x^3 = 0 (2)\\
$

将$y=3+x$带入(2)式，并化简得

$x^3 - x(3+x) = 0 \\
x(x^2 - x - 3) = 0 \\
$

得到x得负数解为：$x =\frac{1 - \sqrt{13}}{2}$

则$x + y = 2x + 3 = 1 - \sqrt{13} + 3 = 4 - \sqrt{13}$

答案选择C
