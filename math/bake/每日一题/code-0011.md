# code-0011

已知$(x^2 + ax + b)^{10} = (x + 5)^{20} - (cx + d)^{20}$，

其中a，b，c，d均为实数，求a，b，c，d的值。

**解题思路：**

1. 首先确定为恒等式，可以带入任意值, 先带入-5，消掉一项计算关系
2. 根据最高位的系数，确定c的值，之后可计算d的值
3. 剩余计算a, b的值

**解:**

令$x = -5$, 则有$(25 - 5a + b)^{10} + (5c + d)^{20} = 0$

则有
$
\begin{cases}
25 - 5a + b = 0 \\
5c + d = 0 \\
\end{cases}
$

另外x最高位为x^20，且左边系数确定1，右边确定为$1 - c^{20}$。

可得$1 - c^{20} = 1$，算出$c = 0$。

带入上式则$d = 0$。

将$c=0，d=0$带入公式转换为

$
(x^2 + ax + b)^{10} \\
= (x + 5)^{20} \\
= (x^2 + 10x + 25)^{10}$,

为了满足恒等，则二项式的值也相等.

计算可得$a = 10, b = 25$。

综上可知，结果如下：

$
\begin{cases}
a = 10 \\
b = 25 \\
c = 0 \\
d = 0
\end{cases}
$
