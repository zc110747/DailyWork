# code-0005

问题: 实数$x + y + z = 5，xy + yz + xz = 3$，则z的最大值是多少。

**解题思路:**

1. 构建x + y和xy得方程组
2. 根据韦达定理构建方程，基于方程有解，计算出范围

**解:**

由上式可知:

$
x + y = 5 - z， \\
xy = 3 - z(x+y) \\
= 3 - z(5 - z) \\
= z^2 - 5z + 3 \\
$

要满足x，y为实数，根据韦达定理，可得到关于t的一元二次方程组，x、y为方程的解。

$t^2 - (5-z)t + (z^2 - 5z + 3) = 0，且\Delta > 0$。

带入计算得：

$
\Delta = (5-z)^2 - 4(z^2 - 5z + 3) \\
= -3z^2 + 10z + 13 \\
= -(3z -13)(z+1) >= 0
$

即$(3z - 13)(z + 1) <= 0$，则z的取值范围为$-1 <= z <= \frac{13}{3}$。

则允许z最大值即为$\frac{13}{3}$。
