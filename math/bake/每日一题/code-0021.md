# 最大值问题

已知$x，y，z \in R+，且x^2 + y^2 + z^2 + xyz = 4$，求$x + y + z$的最大值?  

**解题思路:**

**解:**

已知$x，y，z > 0$，可得$x^2 + y^2 + z^2 = 4 - xyz < 4$，可知$x，y，z < 2$。

已知公式如下:

$yz = \frac{1}{4} * (2yz + 2yz)$

$yz <= \frac{1}{4}(y^2 + z^2 + 2yz)$

$yz <= \frac{1}{4}(y + z)^2$

当$y = z$时相等时满足等于要求。

根据$x^2 + y^2 + z^2 + xyz = 4$，处理得

$x^2 - 4 + y^2 + z^2 + 2yz = 2yz - xyz$

$x^2 - 4 + y^2 + z^2 + 2yz = (2 - x)yz$

$(y + z)^2 - (2 - x)yz = (2 + x)(2 - x)$

将yz带入，可得式子如下。

$(y + z)^2 - \frac{1}{4}(2-x)(y+z)^2 \leq (2 + x)(2 - x)$

$\frac{1}{4}(2 + x)( y + z)^2 \leq (2 + x)(2 - x)$

因为x > 0, 可同时约掉$(2 + x)$，得：

$(y + z)^2 \leq 4(2 - x)$

因为y + z > 0，2 - x > 0，两边可同时开根号得到。

$y + z \leq 2 \sqrt{2-x}$

$y + z \leq 1^2 + （\sqrt{2 - x})^2$

$y + z \leq 3 - x$

由上述可得$x + y + z \leq 3$。此时2-x = 1, x = 1, 同时y = z, 带入可得y = 1, z = 1。

综合可知，当$x = 1，y = 1，z = 1$时可得最大值为3。
