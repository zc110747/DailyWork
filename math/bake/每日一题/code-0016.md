题目: 已知不同的自然数满足$\frac{1}{（）} + \frac{1}{（）} = \frac{2}{19}$，填空使等式成立。

解题思路:

1. 通分，构建方程进行处理。

**解:**

设两个数分别为a，b，则

$\frac{a + b}{ab} = \frac{2}{19}$

定义系数为n，n大于0，则

$a + b = 2n \\
a * b = 19n$

由上述式子可以得到，a、b是$x^2 - 2nx + 19n = 0$得解。

可得a、b的解为$\frac{2n \pm \sqrt{4n^2 - 76n}}{2} = n \pm \sqrt{n^2 - 19n}$。

因为a，b不相等且为自然数

则n不等于19，且需要n^2 - 19n > 0, 同时是完全平方数。

令$n^2 - 19n = m^2$，m为整数，则$n^2 - 19n - m^2 = 0$，满足n > 19, n为整数

则$\frac{19 \pm \sqrt{361 + 4m^2}}{2}$也为整数，可得361 + 4m^2 是完全平方数。

另361 + 4m^2 = y^2，y为整数

(y + 2m)(y - 2m) = 361，其中y和m均为整数。

因为361为质数，则只有唯一分解1和361。

$y + 2m = 361 \\
y - 2m = 1$

解得y = 181, m = 90

带入化简，可得$n = \frac{19 + 181}{2} = 100$。

将n = 100带入化简得$100 \pm \sqrt{100^2 - 19 \times 100} = 100 \pm 90$，则a，b的解为190, 10
