已知正整数a，b，c，d，且$3^a + 2*3^b = 3^c$

1. 求证: a = b。
2. 若a + b = cd，求a + b + c + d的最小值。

**解：**

已知$3^a + 2*3^b = 3^c$，两边同时除$3^a$。

可得：$1 + 2 * 3^{(b - a)} = 3^{(c-a)}$。

由上式可知，$3^{(c-a)} > 1$，可得$c > a$。

因为$c，a$为正整数，则$c - a$为正整数，且$c - a \geq 1$。

可得$3^{(c-a)}$为3的正整数倍，能够被3整除。

同理$1 + 2 * 3^{(b - a)}$也能够被3整除，下面分三种情况讨论处理。

（1）当$b < a$时，此时$0 < 3^{(b-a)} < 1$，左边转换如下：

$1 + 2 * 3^{(b - a)} = 3 + 2(3^{(b−a)} - 1)$

可得$1 < 3 + 2(3^{(b−a)} - 1) < 3$，不可能被3整除，此情况排除。

（2）当$b = a$时，$1 + 2 * 3^{(b - a)} = 3$， 满足要求。

（3）当$b > a$时，左边转换如下。

$1 + 2 * 3^{(b - a)} =(3 + 2*3^{(b-a)}) - 2$，

此时$b > a$，且$a，b$为正整数；则$b-a \geq 1$ 且为正整数。

此时$3 + 2*3^{b-a}$一定能被3整除，那么$(3 + 2*3^{(b-a)}) - 2$不可能被3整除，此情况同样排除。

综上可知: 只有a = b时可以满足上式，可证a = b。

将$a = b$带入上式，可得$3^c = 3^a + 2*3^a = 3^{(a+1)}$。

化简得c = a + 1。

代入$a + b = cd$，可得$2a = (a + 1)d$，

已知a为正整数，则a + 1 > 0。

可得$d = \frac{2a}{a + 1} = \frac{2}{1 + \frac{1}{a}}$,

因为d也为正整数，则$1 + \frac{1}{a} \leq 2$，可得$a \geq 1$。

计算

$
a + b + c + d \\
= 3a + 1 + \frac{2a}{a + 1} \\
= \frac{3a^2 + 6a + 1}{a+1} \\
= \frac{3(a+1)^2 - 2}{a + 1} \\
= 3(a + 1) - \frac{2}{a+1} \\
$

当a正整数时，可知$3(a + 1)$和$-\frac{2}{a+1}$都随着a增大而增加。

结合$a \geq 1$可得$a = 1$时为最小值。

此时$a + b + c + d = 5$。

其中$a = 1，b = 1，c = 2，d = 1$。
