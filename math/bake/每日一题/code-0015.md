题目: $\frac{18}{49}, \frac{41}{111}, \frac{47}{129}, \frac{51}{139}, 比较大小$

解题思路:

1. 进行分子归一化，在进行二次判断
2. 迭代重复

解题:

通过分子转换为1，上述值转换为: 

$\frac{1}{2 + \frac{13}{18}}, \frac{1}{2 + \frac{29}{41}}, \frac{1}{2 + \frac{35}{47}}, \frac{1}{2 + \frac{37}{51}}$

进行分数部分翻转，大小保持不变。

$\frac{18}{13}, \frac{41}{29}, \frac{47}{35}, \frac{51}{37}$

同时减1，大小保持不变。

$\frac{5}{13}, \frac{12}{29}, \frac{12}{35}, \frac{14}{37}$

再将分支转换为1，上述值转换为：

$\frac{1}{2 + \frac{3}{5}}, \frac{1}{2 + \frac{5}{12}}, \frac{1}{2 + \frac{11}{12}}, \frac{1}{2 + \frac{9}{14}}$

进行分数部分翻转，大小保持不变。

$\frac{5}{3}, \frac{12}{5}, \frac{12}{11}, \frac{14}{9}$

同时减1，大小保持不变

$\frac{2}{3}, \frac{7}{5}, \frac{1}{11}, \frac{5}{9}$

按照顺序:

$\frac{7}{5} > \frac{2}{3} > \frac{5}{9} > \frac{1}{11}$

可得

$\frac{41}{111} > \frac{18}{49} > \frac{51}{139} > \frac{47}{129}$。
