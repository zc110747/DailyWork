## q1

1. 设$x \in R$，集合$\{x, \sqrt{2x}, x^2\} = \{x-4, x^2- 12x + 40, 8x\}$, 则x的值是多少。

**解题思路：**

1. 集合等价，可以令x分别等于右边的三个值，排除不存在项，计算出x。
2. 将x代入集合中，验证是否成立。

**解：**

1. x值等于x - 4, 不成立。
2. x值等于8x，计算出x=0, 左边为$\{0， 0， 0\}$， 右边为$\{-4, 40, 0\}$, 不成立。
3. x值等于$x^2- 12x + 40$，得公式$x^2- 13x + 40 = 0$, 则x值为$\frac{13 \pm 3}{2}$，根为5和8，带入集合验证。
4. x = 5， 带入集合验证为，左边为$\{5， \sqrt{10}， 25\}$， 右边不存在无理数，不成立。
5. x = 8, 带入集合验证为，左边为$\{8， 4， 64\}$， 右边为$\{4， 8, 64\}$, 此时成立，则x=8。

## q2

设n为正整数，定义$P_n(cosx) = cosnx$, 则

$P_{2025}(cos5^\circ) + 2cos(185^\circ)P_{2024}(cos5^\circ) + P_{2023}(sin85^\circ)得值$

**解题思路：**

1. 公式$sinx = cos(90^\circ - x)$
2. 公式$cos(180^\circ + x) = -cosx$。
3. 公式$cos(m+n) = cos(m)cos(n) - sin(m)sin(n)$
4. 公式$cos(m-n) = cos(m)cos(n) + sin(m)sin(n)$

**解：**

原式得值 = $cos(2025*5^\circ) + 2cos(185^\circ)cos(2024*5^\circ) + P_{2023}(cos5^\circ)$
        = $cos(2025*5^\circ) - 2cos(5^\circ)cos(2024*5^\circ) + cos(2023*5^\circ)$

公式转换: $cos(2025*5^\circ) = cos(2024*5^\circ + 5^\circ) = cos(2024*5^\circ)cos(5^\circ) - sin(2024*5^\circ)sin(5^\circ)$

公式转换: $cos(2023*5^\circ) = cos(2024*5^\circ - 5^\circ) = cos(2024*5^\circ)cos(5^\circ) + sin(2024*5^\circ)sin(5^\circ)$

则$cos(2025*5^\circ) + cos(2023*5^\circ)  =  2cos(2024*5^\circ)cos(5^\circ)$

原式得值 = $2cos(2024*5^\circ)cos(5^\circ) - 2cos(5^\circ)cos(2024*5^\circ) = 0$；

## q3

若等差数列${a_n}$满足：$a_1>0，S_7 + a_4 = 0$，其中$S_7$为数列前7项和，则使得$2Sn \geq  a_n$得最大值是多少。

**解题思路：**

1. 等差数列公式$a_n = a_1 + (n-1)d$
2. 等差数列前n项和公式$Sn = \frac{n}{2}(a_1 + a_n) = na_1 + \frac{n(n-1)d}{2}，带入S_7 + a_4 = 0, 求出a1和d得关系$
3. 将$2Sn \geq a_n$带入化简，求$a_n$满足时n得最大n整数值(数列项为正整数)

**解：**

等差数列公式$a_n = a_1 + (n-1)d$，求和公式$Sn = \frac{n}{2}(a_1 + a_n) = na_1 + \frac{n(n-1)d}{2}$。

带入$S_7 + a_4 = 0$, 求出a1和d得关系:

$7a_1 + 21d + a_1 + 3d = 0$，则$a_1 = -3d$， 已知a_1 > 0, 则d。

带入$2Sn \geq  a_n$，化简得:

$2na_1 + n(n-1)d \geq  a_1 + (n-1)d, 带入a_1 = -3d得$，

$-3(2n - 1)d + (n-1)^2d \geq  0$, 因为d < 0, 则

$-3(2n - 1) + (n - 1)^2 \geq  0$

$n^2 - 8n + 4 <= 0$

解得，$ 4 - 2\sqrt{3}  < n < 4 + 2\sqrt{3}$，因为$\sqrt{3}$约等于1.7, 则$ 0.6 < n < 7.4$, 则$n$取整后得最大值为7。

## q7

设$x，y，z \in R$，且$5x^2 + 6y^2 + 6z^2 - 8yz <= 1$，则$x + y + z$得最大值。

**解题思路:**

1. 首先对给定的二次型进行配方处理，将其转化为标准形式
2. 然后利用柯西不等式求极值

**解:**

对二次型进行配方： 将不等式 $5x^2 + 6y^2 + 6z^2 - 8yz \leq 1$ 中的 $y,z$ 部分配方：
$
6y^2 + 6z^2 - 8yz \\
= 6(y^2 - \frac{4}{3}yz) + 6z^2 \\
= 6[(y - \frac{2}{3}z)^2 - \frac{4}{9}z^2] + 6z^2 \\
= 6(y - \frac{2}{3}z)^2 - \frac{8}{3}z^2 + 6z^2 \\
= 6(y - \frac{2}{3}z)^2 + \frac{10}{3}z^2$

则原不等式可以表示为： 

$5x^2 + 6(y - \frac{2}{3}z)^2 + \frac{10}{3}z^2 \leq 1$

设$u = \sqrt{5}x$, $v = \sqrt{6}(y - \frac{2}{3}z)$, $w = \sqrt{\frac{10}{3}}z$， 

则不等式变为 $u^2 + v^2 + w^2 \leq 1$

表达式 $x + y + z$ 可以表示为： 

$
x + y + z = \frac{u}{\sqrt{5}} + \frac{v}{\sqrt{6}} + \frac{2}{3\sqrt{6}}w + \frac{w}{\sqrt{\frac{10}{3}}} \\
= \frac{u}{\sqrt{5}} + \frac{v}{\sqrt{6}} + (\frac{2}{3\sqrt{6}} + \sqrt{\frac{3}{10}})w
$

根据柯西不等式：

$
(x + y + z)^2 \leq (\frac{1}{5} + \frac{1}{6} + (\frac{2}{3\sqrt{6}} + \sqrt{\frac{3}{10}})^2)(u^2 + v^2 + w^2) \leq \frac{1}{5} + \frac{1}{6} + (\frac{2}{3\sqrt{6}} + \sqrt{\frac{3}{10}})^2
$

最大值出现在等号成立时，即： $\frac{u}{1/\sqrt{5}} = \frac{v}{1/\sqrt{6}} = \frac{w}{\frac{2}{3\sqrt{6}} + \sqrt{\frac{3}{10}}}$

最终计算可得 $x + y + z$ 的最大值为 $\frac{\sqrt{30}}{5}$。

验证: 当 $x = \frac{\sqrt{30}}{30}$, $y = z = \frac{\sqrt{30}}{12}$ 时， $5x^2 + 6y^2 + 6z^2 - 8yz = \frac{5}{30} + \frac{6}{12} + \frac{6}{12} - \frac{8}{12} = 1$， 且 $x + y + z = \frac{\sqrt{30}}{5}$。
