## q1-01

用$[x]$表示不超过x的最大整数，把$x - [x]$称为x的小数部分。已知$t = \frac{1}{2 - \sqrt{3}}$，a是t的小数部分，b是-t的小数部分，则$\frac{1}{2b} - \frac{1}{a}$的值是多少。

解题思路:

1. 化简t，计算a，b基于小数定义的实际值
2. 带入运算

解:

t化简，$t = 2 + \sqrt{3}$, 

t的值在$(3, 4)$之间，则$a = t - 3 = \sqrt{3} - 1$,

-t的值在$(-4, -3)$之间，则$b = -t + 4 = 2 - \sqrt{3}$,

则$\frac{1}{2b} - \frac{1}{a}$的值为$\frac{1}{2(2-\sqrt{3})} - \frac{1}{\sqrt{3} - 1}$ = $\frac{2 + \sqrt{3}}{2} - \frac{\sqrt{3} + 1}{2} = \frac{1}{2}$

## q1-02

三种图书的的单价分别为10元、15元、20元，某学校恰好用500元购买上述图书30本，那么不同的购书方案有多少种？

解题思路:

得10x + 15y + 20z = 500, x + y + z = 30, 转换为y，z关于x的公式，计算x的范围。

解:

由上述可得公式。

$
\begin{cases}
    10x + 15y + 20z = 500 \\
    x + y + z = 30
\end{cases}
$

分别消除y, z；得到

$
\begin{cases}
y = 20 - 2x \\
z = x + 10 \\
\end{cases}
$

其中y >= 0, z >= 0, 则x的范围为[0, 10]，共有11种。

## q1-03

解题思路:

转换为公式，$(2n + 1)^3 -  (2n - 1)^3 <= 2016$，进行化简

解:

$(2n + 1)^3 -  (2n - 1)^3 <= 2016 \\
(2n + 1 - 2n + 1)((2n + 1)^2 + (2n - 1)^2 + (2n - 1)(2n - 1)) <= 2016 \\
2(12n^2 + 1) <= 2016 \\
n^2 < 83
$

则n的值可选为[0, 9], 即和谐数有10个，其和为

$(1^3 - (-1)^3) + (3^3 - 1^3) + ... (19^3 - 18^3) \\
= 19^3 - (-1)^3 \\
= 6860  \\
$

## q1-04

已知二次函数$y = ax^2 + bx + 1(a \neq 0)$的图像的顶点在第二象限，且过点(1,0), 当$a-b$是整数时，求$ab$的值。

解题思路:

1. 带入(1, 0)点，计算a, b的关系，转换$a - b$
2. 根据顶点和过点，得出图形的方向，中分线范围

解:

将(1, 0)点带入的$b = - 1 - a$, 则$a - b = 2a + 1$，

因为顶点在第二象限，则$a < 0$, 且$-\frac{b}{2a} < 0$, 

带入$b = - 1 - a$, 得 $a + 1 > 0$, 即$-1 < a < 0$, 则$-1 < 2a + 1 < 1$

若$a - b$是整数，则$2a + 1$是整数，值为0，此时$a = \frac{1}{2}$, 带入公式得$b = \frac{1}{2}$，则$ab = \frac{1}{4}$。

## q1-07

设实数x, y, z满足$x + y + z = 1$, 则$M = xy + 2yz + 3xz$的最大值是多少。

解题思路:

1. 转换为公式，将z替换成1-x-y，进行配平方计算

解:

$M = xy + 2yz + 3xz \\
= xy + (2y + 3x)(1 - x - y) \\
= xy + 2y - 2xy - 2y^2 + 3x - 3x^2 - 3xy \\
= -3x^2 - 4xy - 2y^2 + 3x + 2y \\
= -2(x^2 + y^2 + \frac{1}{4} + 2xy - y - x) - x^2 + x - \frac{1}{4} + \frac{1}{4} + \frac{1}{2} \\
= -2(x + y - \frac{1}{2})^2 - (x - \frac{1}{2})^2 + \frac{3}{4} \\
$

则当$x + y = \frac{1}{2}，x = \frac{1}{2}$时，值最大为$\frac{3}{4}$。


题目扩展：

已知$x + y + z = 1，M = axy + byz + cxz$

其中$a，b，c为正整数且c = a + b$, 证明M的最大值为$c/4$, 

$axy + byz + cxz \\
= axy + z(by + cx) = axy + (by + cx)(1 - x - y) \\
= axy + by - bxy - by^2 + cx - cx^2 - cyx \\
= -cx^2 + (a - c - b)y^2 - by^2 + cx + by \\
= - cx^2 - 2bxy - by^2 + cx + by \\
=  - b(x^2 + y^2 + \frac{1}{4} + 2xy - y - x) - (c - b)x^2 + (c - b)x + \frac{b}{4} \\
= -b(x + y - \frac{1}{2})^2 - ax^2 + ax - \frac{a}{4} + \frac{(a + b)}{4} \\
= - b(x + y - \frac{1}{2})^2 - a(x^2 - x + \frac{1}{4}) + \frac{c}{4} \\
= - b(x + y - \frac{1}{2})^2 - a(x - \frac{1}{2})^2 + \frac{c}{4} \\
$

因为a > 0, b > 0, 则当$x + y = \frac{1}{2}, x = \frac{1}{2}$时。

M的最大值为$\frac{c}{4}$。

基于上述证明，可以得出

$M = xy + yz + 2xz$，最大值为$\frac{1}{2}$

$M = xy + 3yz + 4xz$，最大值为$1$

$M = xy + 4yz + 5xz$，最大值为$\frac{5}{4}$

$M = 2xy + 3yz + 5xz$，最大值为$\frac{5}{4}$
