## 初中数学竞赛题目

### 选择题部分

**题目1**
设$x \in R$，集合$\{x, \sqrt{2x}, x^2\} = \{x-4, x^2-12x + 40, 8x\}$，则x的值是多少。

**题目2**
已知实数a≠b，且满足$(a+1)^2 = 3-3(a+1)$，$3(b+1) = 3-(b+1)^2$，则$\frac{b\sqrt{\frac{b}{a}} + a\sqrt{\frac{a}{b}}}{a+b}$的值为（）

**题目3**
若直角三角形的两条直角边长为a、b，斜边长为c，斜边上的高为h，则有（）

**题目4**
一条抛物线$y = ax^2 + bx + c$的顶点为$(4,-11)$，且与x轴的两个交点的横坐标为一正一负，则a、b、c中为正数的（）

**题目5**
假如x和y是非零实数，使得$|x| + y = 3$和$|x|y + x^3 = 0$，那么$x + y$等于（）

**题目6**
设n为正整数，定义$P_n(\cos x) = \cos nx$，则$P_{2025}(\cos 5°) + 2\cos(185°)P_{2024}(\cos 5°) + P_{2023}(\sin 85°)$的值为（）

**题目7**
非负实数x、y、z满足$x + y + z = 1$，则$t = 2xy + yz + 2xz$的最大值为（）

**题目8**
设$[t]$表示不超过实数t的最大整数，令$\{t\} = t - [t]$。已知实数x满足$x^3 + \frac{1}{x^3} = 18$，则$\{x\} + \{\frac{1}{x}\}$的值为（）

**题目9**
6张不同的卡片上分别写有数字2, 2, 4, 4, 6, 6，从中取出3张，则这3张卡片上所写的数字可以作为三角形的三边长的概率是（）

**题目10**
在△ABC中，$\angle C = 90°$，$\angle A = 60°$，AC = 1，D在BC上，且$\angle BAD = 30°$，则BD的长度为（）

### 填空题部分

**题目11**
用$[x]$表示不超过x的最大整数，把$x - [x]$称为x的小数部分。已知$t = \frac{1}{2 - \sqrt{3}}$，a是t的小数部分，b是-t的小数部分，则$\frac{1}{2b} - \frac{1}{a}$的值是______。

**题目12**
化简$\sqrt[3]{\sqrt{5} + 2}$的值为______。

**题目13**
已知实数a、b、c满足$a + b + c = 0$，$a^2 + b^2 + c^2 = 1$，则$\frac{a^5 + b^5 + c^5}{abc}$的值是______。

**题目14**
已知实数a、b、x、y满足$a + b = x + y = 2$，$ax + by = 5$，则$(a^2 + b^2)xy + ab(x^2 + y^2)$的值是______。

**题目15**
实数$x + y + z = 5$，$xy + yz + xz = 3$，则z的最大值是______。

**题目16**
三种图书的单价分别为10元、15元、20元，某学校恰好用500元购买上述图书30本，那么不同的购书方案有______种。

**题目17**
设x、y、z ∈ R，且$5x^2 + 6y^2 + 6z^2 - 8yz ≤ 1$，则$x + y + z$的最大值是______。

**题目18**
求$\sqrt[6]{99 + 70\sqrt{2}}$的值是______。

**题目19**
已知$x^5 = -1$，则$x + \frac{1}{x}$的值为______。

**题目20**
设实数x、y、z满足$x + y + z = 1$，则$M = xy + 2yz + 3xz$的最大值是______。

### 解答题部分

**题目21**
如果有一个正整数可以表示为两个连续奇数的立方差，则称为这个正整数为"和谐数"。如：$2 = 1^3 - (-1)^3$，$26 = 3^3 - 1^3$，2和26都是和谐数。那么不超过2016的正整数中，和谐数有几个？和是多少？

**题目22**
已知二次函数$y = ax^2 + bx + 1(a \neq 0)$的图像的顶点在第二象限，且过点(1,0)，当$a - b$是整数时，求$ab$的值。

**题目23**
已知等差数列$\{a_n\}$的前三项分别为$a_1$、$a_2$、$a_3$，满足$a_1 + a_2 = 6$，$a_2 + a_3 = 10$。

(1) 求数列$\{a_n\}$的通项公式。

(2) 求数列$\{a_n + a_{n+1}\}$的前n项和。

**题目24**
已知a、b是实数，关于x、y的方程组
$$
\begin{cases}
y = x^3 - ax^2 - bx \\
y = ax + b
\end{cases}
$$
有整数解$(x, y)$，求a、b的取值范围。

**题目25**
在△ABC中，AB = AC，D为BC的中点，BE ⊥ AC于E，交AD于P，已知BP = 3，PE = 1，求AE的长度。

**题目26**
设实数x、y、z ∈ R⁺，且$x^2 + y^2 + z^2 + xyz = 4$，求$x + y + z$的最大值。

**题目27**
若等差数列$\{a_n\}$满足：$a_1 > 0$，$S_7 + a_4 = 0$，其中$S_7$为数列前7项和，则使得$2S_n \geq a_n$的最大值是多少？

**题目28**
已知$(x^2 + ax + b)^{10} = (x + 5)^{20} - (cx + d)^{20}$，其中a、b、c、d均为实数，求a、b、c、d的值。

**题目29**
已知不全等的a、b、c，满足如下等式：
$$
\begin{cases}
a = ab + c \\
b = bc + a \\
c = ca + b
\end{cases}
$$
求$a + b + c$的值。

**题目30**
已知正整数a、b、c、d，且$3^a + 2 \cdot 3^b = 3^c$。

(1) 求证：$a = b$。

(2) 若$a + b = cd$，求$a + b + c + d$的最小值。

## 高中数学竞赛题目

### 代数题部分

**题目1**
设锐角θ使关于x的方程$x^4 \cos^2 \theta - x^2 \cot \theta + 1 = 0$有重根，则θ的弧度数为（）

**题目2**
已知M = $\{(x,y) | x^2 + y^2 \leq 3\}$，N = $\{(x,y) | y = mx + b\}$。若对所有m ∈ R，均有M ⊆ N，则b的取值范围是（）

**题目3**
不等式$\log_1 x^3 \cdot 2 \leq 0$的解集是（）

**题目4**
设点O在△ABC内部，且有$\vec{OA} + 2\vec{OB} + 3\vec{OC} = \vec{0}$，则△ABC的面积与△AOC的面积的比为（）

**题目5**
设三位数n = $\overline{abc}$，若以a、b、c为三条边的长可以构成一个等腰（含等边）三角形，则这样的三位数n有（）

**题目6**
顶点为P的圆锥的轴截面是等腰直角三角形，A是底面圆周上的点，B是底面圆内的点，O为底面圆的圆心，AB ⊥ OB，垂足为B，OH ⊥ PB，垂足为H，且PA = 4，C为PA的中点。则当三棱锥O-HPC的体积最大时，OB的长是（）

**题目7**
多项式f(x)满足：对于任意x ∈ R，都有$f(x+1) + f(x-1) = 2x^2 - 4x$，则f(x)的最小值是______。

**题目8**
数列$\{a_n\}$、$\{b_n\}$满足：$a_n = n^k$，$k = 1, 2, \ldots, n$，已知数列$\{a_n\}$的前n项和为$S_n = \frac{n(n+1)(n+2)}{6}$，则数列$\{b_n\}$的前n项和$B_n$ = ______。

**题目9**
函数$f(x) = \frac{x^2 + 2x + 3}{x^2 + 4x + 6}$的值域是______。

**题目10**
设M = $\{a^k, b^l\} \setminus \{ad, bc\}$，$m \in M$。对于n ∈ N，定义M的n次幂$M^n$。

(1) 当n = 3时，求6元素集M = $\{a, b, c, d, e, f\}$所能构成的"幂集"数；

(2) 对于一般的n ≥ 2，求由2n元素集M所能构成的"幂集"T(n)。

**题目11**
在△ABC中，已知$\frac{1}{BC} \cdot \frac{1}{CA} = \frac{1}{AB} \cdot \frac{1}{AC}$，$BC = 4$，$AC \cdot BC = -4$，则AC = ______。

**题目12**
从集合$\{3, 4, 5, 6, 7, 8\}$中随机选取3个不同的数，这3个数可以构成等差数列的概率为______。

**题目13**
已知a是实数，方程$x^2 + (4+i)x + ai^+ + = 0$的一个实根是b（i是虚部单位），则$|a + bi|$的值为______。

**题目14**
在平面直角坐标系xOy中，双曲线C：$\frac{x^2}{12} - \frac{y^2}{4} = 1$的右焦点为F，一条过原点O且倾斜角为锐角的直线l与双曲线C交于A、B两点。若△FAB的面积为2，则直线的斜率为______。

**题目15**
已知a是正实数，$\log_a 2 + \log_2 a = k$，则k的取值范围是______。

**题目16**
在四面体ABCD中，$AB = AC = AD = 5$，$BC = 3$，$CD = 4$，该四面体的体积为______。

**题目22**（2007年全国高中数学联赛）

### 解析几何题部分

试问：当且仅当a、b满足什么条件时，对C₁上任意一点P，均存在以P为顶点，与C₀外切，与C₁内接的平行四边形？并证明你的结论。

**题目29**（2002年全国高中数学联赛）
已知点A(0, 2)和抛物线y² = x + 4上两点B、C，使得AB ⊥ BC，求点C的纵坐标的取值范围。

**题目30**（2006年全国高中数学联赛）

**题目31**（2008年全国高中数学联赛）

**题目32**

### 数列与函数题部分

**题目33**
已知等差数列$\{a_n\}$和等比数列$\{b_n\}$满足：$a_1 = b_1 = 1$，$a_2 = b_2 = 3$，$a_3 + b_3 = 10$。

求：
(1) 等差数列$\{a_n\}$的公差d和等比数列$\{b_n\}$的公比q；
(2) 满足$S_n < T_n$的最大正整数n，其中$S_n$和$T_n$分别为$\{a_n\}$和$\{b_n\}$的前n项和。

**题目34**
设函数$f(x) = \sin^2 x + \sin^2(x + \frac{\pi}{3}) + \sin^2(x + \frac{2\pi}{3})$。

(1) 求函数$f(x)$的周期；
(2) 求函数$f(x)$的值域。

**题目35**
已知数列$\{a_n\}$满足：$a_1 = 1$，$a_{n+1} = \frac{a_n + 2}{a_n + 1}$（n ∈ N*）。

(1) 求数列$\{a_n\}$的通项公式；
(2) 求数列$\{a_n\}$的前n项和$S_n$。

**题目36**
设函数$f(x) = x^3 + ax^2 + bx + c$在$x = -1$和$x = 2$处有极值。

(1) 求a、b的关系；
(2) 若$f(0) = f(1) = f(3)$，求f(x)的表达式。

**题目37**
已知函数$f(x) = \ln x - ax + 1$（a为常数）。

(1) 当a = 1时，求函数$f(x)$的极值；
(2) 若函数$f(x)$有两个零点，求a的取值范围。

**题目38**
设数列$\{a_n\}$满足：$a_1 = \frac{1}{2}$，$a_{n+1} = \frac{1}{2}(a_n + \frac{1}{a_n})$（n ∈ N*）。

证明：数列$\{a_n\}$单调递减，并求$\lim_{n \to \infty} a_n$。

### 综合应用题部分

**题目39**
小川野升平想在一个边长为6米的正方形的地块上建造一个有一堵墙的房子，墙要用沙发垫、玻璃门中的一种建造，沙发垫墙每平方米需要50元，玻璃门墙每平方米需要80元。

为了满足小川野升平的预算，需要选择合适的方案，可以使花费尽可能少。请求出该房子沙发垫墙和玻璃门墙各多少平方米，以及花费的最小值。

**题目40**
已知$x, y, z \in \mathbb{R}^+$，且$x^2 + y^2 + z^2 + xyz = 4$。

(1) 求证：$x + y + z \leq 3$；
(2) 当$x + y + z$取得最大值时，求$x, y, z$的值。

**题目41**
设$a, b, c$为正实数，满足$a + b + c = 1$。

证明：$\frac{a^2}{b} + \frac{b^2}{c} + \frac{c^2}{a} \geq a + b + c$。

**题目42**
已知$a, b, c$为正实数，满足$ab + bc + ca = 1$。

求证：$\frac{a}{\sqrt{a^2 + 1}} + \frac{b}{\sqrt{b^2 + 1}} + \frac{c}{\sqrt{c^2 + 1}} \leq \frac{3}{2}$。

**题目43**
设$a, b, c$为正实数，满足$a + b + c = 3$。

证明：$\frac{a^3}{b} + \frac{b^3}{c} + \frac{c^3}{a} \geq a^2 + b^2 + c^2$。

**题目44**
已知数列$\{a_n\}$满足：$a_1 = 1$，$a_{n+1} = a_n + \frac{1}{a_n}$（n ∈ N*）。

(1) 证明：$a_n < \sqrt{2n}$对一切正整数n成立；
(2) 求证：$\sum_{k=1}^n \frac{1}{a_k} < \frac{2}{3}a_n$。

**题目45**
设函数$f(x) = e^x - x - 1$。

(1) 求函数$f(x)$的单调区间；
(2) 证明：对于任意$x > 0$，都有$e^x > x + 1$；
(3) 利用上述结论，证明数列$\{a_n\}$（其中$a_n = (1 + \frac{1}{n})^n$）单调递增且有上界。

## 题目来源说明

本套竞赛题目主要来源于以下几个方面：

### 初中部分
1. **全国初中数学竞赛真题**：包括2001年、2004年、2008年、2009年、2014年、2018年、2021年等历年真题
2. **数学竞赛浙江初赛题目**：参考了浙江省初中数学竞赛的经典题型
3. **全国初中数学联合竞赛试题**：包含选择题、填空题和解答题

### 高中部分
1. **全国高中数学联赛试题**：2000年至2018年历年真题
2. **平面几何赛题精选**：包含了2000-2007年联赛二试几何题
3. **解析几何专题**：涵盖了圆锥曲线、圆、抛物线等经典题型
4. **数列与函数专题**：等差等比数列、函数性质、极限等

### 项目现有内容
本套题目还结合了项目中的"每日一题"系列，包括：
- 方程与不等式问题
- 数列求和问题
- 几何证明问题
- 实数运算问题

## 使用建议

### 初中阶段
1. **基础训练**：建议从选择题入手，掌握基本概念和计算技巧
2. **专项突破**：针对填空题和解答题，分模块进行练习
3. **综合提升**：在掌握基础知识后，进行综合性题目的训练

### 高中阶段
1. **代数基础**：重点掌握函数、不等式、复数等基础知识
2. **几何证明**：平面几何需要掌握基本定理和证明方法
3. **解析几何**：熟练运用坐标系解决几何问题
4. **数列函数**：注重通项公式、求和公式、函数性质的应用

### 训练建议
1. **时间分配**：建议每天安排2-3小时进行竞赛题目训练
2. **错题整理**：建立错题本，记录解题思路和易错点
3. **模拟考试**：定期进行模拟考试，检验学习效果
4. **查漏补缺**：针对薄弱环节，进行针对性训练

### 竞赛准备
1. **知识点梳理**：系统整理竞赛涉及的所有知识点
2. **解题技巧**：总结常用的解题方法和技巧
3. **真题演练**：大量练习历年真题，熟悉出题规律
