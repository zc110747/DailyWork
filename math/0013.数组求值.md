# code-0008

已知实数a，b，c满足$a + b + c = 0，a^2 + b^2 + c^2 = 1$，求$\frac{a^5 + b^5 + c^5}{abc}$的值。

**解题思路:**

1. 对于填空题，假定c为符合要求的值，带入计算即可
2. 利用公式当a+b+c=0时，满足$a^5+b^5+c^5=-5abc(ab+bc+ca)$

**解：**

由$a^2 + b^2 + c^2 = 1$可知，c的值在$(-1，1)$之间，且不能为0，假定c = 1/2，可得公式

$
\begin{cases}
a + b = -1/2 \\
a^2 + b^2 = 3/4 \\
c = 1/2 \\
\end{cases}
$

可得$ab = \frac{((a + b)^2 - (a^2  + b^2))}{2} = -\frac{1}{4}$

同理计算可得。

$
a^3 + b^3 = (a^2 + b^2)(a + b) - ab(a+b) \\
= \frac{3}{4}*(-\frac{1}{2}) - (-\frac{1}{4})*(-\frac{1}{2}) \\
= -\frac{1}{2}
$。

$
a^5 + b^5 = (a^3 + b^3)(a^2 + b^2) - (ab)^2(a+b) \\
= (-\frac{1}{2})*(\frac{3}{4}) - (-\frac{1}{4})^2*(-\frac{1}{2}) \\
= -\frac{11}{32}
$。

则
$
\frac{a^5 + b^5 + c^5}{abc} \\
= \frac{-\frac{11}{32} + \frac{1}{32}}{(-\frac{1}{4})*{\frac{1}{2}}} \\
= \frac{-\frac{10}{32}}{-\frac{1}{8}} \\
= \frac{5}{2}
$

则最终值为：$\frac{5}{2}$。
